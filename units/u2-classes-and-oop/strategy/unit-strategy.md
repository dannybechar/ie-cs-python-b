# Unit 2 — Classes & Object-Oriented Programming

**12h = 2 Theory + 10 Practice = 6 double meetings**
Source: [`python-c.pdf`](../../../docs/ministry-source/python-c.pdf) Unit 2. Framing: [`../../../docs/annual-strategy.md`](../../../docs/annual-strategy.md).

**Build status:** ❌ not started.

## Official scope
Object-oriented approach, class, attributes, constructor, methods,
objects/instances, encapsulation, procedural abstraction/black box,
inheritance, extending Turtle with additional attributes and methods,
algorithmic problem solving using classes.

## Meeting 1 — Knowledge + Lab — Class mental model
Class vs. object, attributes, constructor, instance creation, methods.
Lab: read and modify a small class, create multiple objects, inspect
different object state.

## Meeting 2 — Knowledge + Lab — Encapsulation, abstraction & inheritance
Data/behavior bundled in a class, method as interface to object behavior,
procedural abstraction/black box, inheritance concept, Turtle as the
concrete inheritance vehicle.

## Meeting 3 — Lab + Lab — Design a class for a problem
Identify attributes, identify behaviors, constructor, methods.

## Meeting 4 — Lab + Lab — Multiple objects / multiple classes
Objects with independent state, use several objects in one algorithm,
where appropriate use more than one class.

## Meeting 5 — Lab + Lab — Extend Turtle
Subclass Turtle, add attributes, add methods, create behavior-specific
objects.

## Meeting 6 — Lab + Lab — Integrated OOP challenge + checkpoint
Define, instantiate, use, trace, explain.

## Exit criteria
The student can define a class appropriate to a problem, implement
constructor/attributes/methods, create/use objects, explain encapsulation
at the required level, use inheritance to extend Turtle, and explain code
that uses objects/classes.

## Depth boundary
Do not expand Core into: deep inheritance hierarchies, abstract base
classes, decorators, metaclasses, design patterns, formal UML beyond
simple planning diagrams if useful.
