# Unit 4 — Keyboard Events, Timer & Animation

**12h = 2 Theory + 10 Practice = 6 double meetings**
Source: [`python-c.pdf`](../../../docs/ministry-source/python-c.pdf) Unit 4. Framing: [`../../../docs/annual-strategy.md`](../../../docs/annual-strategy.md).

**Build status:** ❌ not started.

## Official scope
Event-driven programming review, `onkey`, `onkeypress`, `onkeyrelease`,
`listen`, wait/timer, animation, sound in response to keyboard events,
game development. Official examples include: Digger, Pop It, Brick Ball,
spaceship game, Pacman/Pong at module-summary level.

## Meeting 1 — Knowledge + Lab — Keyboard event model
Key event, key press/key release distinction, listener, handler,
movement/control through keyboard.

## Meeting 2 — Knowledge + Lab — Timer + animation state
Repeated/continued behavior, timer/wait, animation driven by state, sound
as event response.

## Meeting 3 — Lab + Lab — Keyboard-controlled movement
Direction, state, boundaries, modular handlers.

## Meeting 4 — Lab + Lab — Press/release behavior
Sustained input where appropriate, separate handlers, state transitions.

## Meeting 5 — Lab + Lab — Animation / timer / sound
Integrate time-based behavior, update state, feedback.

## Meeting 6 — Lab + Lab — Keyboard-driven game + checkpoint
Multiple controls, animation, event handlers, debugging, explain event
flow.

## Exit criteria
The student can distinguish keyboard event types, register and write
handlers, use keyboard input to control state, integrate keyboard input
with animation/timing, and trace and explain event-driven code.
