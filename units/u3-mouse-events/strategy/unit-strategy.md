# Unit 3 — Mouse Events

**12h = 2 Theory + 10 Practice = 6 double meetings**
Source: [`python-c.pdf`](../../../docs/ministry-source/python-c.pdf) Unit 3. Framing: [`../../../docs/annual-strategy.md`](../../../docs/annual-strategy.md).

**Build status:** ❌ not started.

## Official scope
Event-driven programming review, mouse event on screen vs. mouse event on
Turtle, `onclick`, `ondrag`, listener registration, animation, wait/timer,
sound files, game development. Official examples include: organ with
sound, drawing application, memory game, XO, animation-based game.

## Meeting 1 — Knowledge + Lab — Mouse event model
Event, handler/callback, screen vs. Turtle target, click event, listener
relationship.

## Meeting 2 — Knowledge + Lab — Drag + interaction + animation/sound
`ondrag`, object manipulation, sound as response, animation/timing concept.

## Meeting 3 — Lab + Lab — Object-level interaction
Click/drag on Turtle objects, small drawing or object-manipulation build.

## Meeting 4 — Lab + Lab — Screen-level interaction
Screen clicks, map click coordinates to program behavior, XO-style or
placement-based interaction.

## Meeting 5 — Lab + Lab — Sound / animation integration
Response to event, state update, visible/audible feedback.

## Meeting 6 — Lab + Lab — Mouse-driven mini-game + checkpoint
Event handling, modular handlers, debugging event sequences, explanation
of event flow.

## Exit criteria
The student can distinguish screen and object mouse events, register and
implement handlers, use click/drag interaction, integrate event response
with program state, and build and explain a simple interactive
application/game.
