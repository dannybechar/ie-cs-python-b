# יחידה 4.1 – להכניס בינה לקוד (API)

כיתה ח׳ · AI + Python B · **שיחה עם Gemini מתוך פייתון: פרומפט, f-string ופעולה `ask_the_ai`**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> ה-AI לא יושב בתוך התוכנית שלנו. התוכנית שולחת פרומפט (מחרוזת) דרך ה-API, מחכה, ומקבלת מחרוזת חזרה. עוטפים את זה בפעולה `ask_the_ai` שמחזירה את התשובה עם `return`. את המפתח לא כותבים בקובץ, ולא קוראים ל-API בתוך לולאה.

## דף עזר

```python
# פרומפט עם f-string: האות f לפני המירכאות, המשתנים בתוך { }
prompt = f"Write a short birthday greeting for {name}, who is a very {trait} grandmother."

# הפעולה העוטפת
def ask_the_ai(my_prompt):
    response = client.models.generate_content(
        model="gemini-2.5-flash", contents=my_prompt)
    return response.text

answer = ask_the_ai(prompt)
print(answer)
```

<div dir="rtl">

- את שם המודל (`model=...`) **לא משנים**. את `contents=` אפשר.
- הפרומפט הוא מחרוזת. הטקסט של התשובה נמצא ב-`response.text`.
- מגבלות: עד כ-15 בקשות בדקה ועד 1,500 ביום לכל מפתח. שגיאה **429** = חרגנו מהמכסה, שגיאה **503** = השרת עמוס. הקוד תקין: מחכים ומנסים שוב.
- שלושה כללי זהב: **מתכננים** את הפרומפט (ובודקים בצ'אט) · **שולחים רק מה שצריך** · **לא קוראים ל-API בתוך לולאה** — קודם אוספים, ואז שולחים פעם אחת.
- תשובת ה-AI היא טקסט לבדיקה, לא עובדה. לא כותבים בפרומפט מידע אישי.

</div>

> [!NOTE]
> בקובץ ההתחלה יש **אזור A** — "לקוח" מדומה שמחזיר תשובות קבועות (`[stand-in]`), כדי שהתוכנית תרוץ גם בלי מפתח ובלי אינטרנט. **לא נוגעים באזור A.** הקוד שאתם כותבים מתחתיו זהה לקוד האמיתי.

## 1. חימום: בדיחה שמודפסת כמו אובייקט

פתחו את `AskTheAI_Starter.py` והריצו אותו. התוכנית אמורה להדפיס בדיחה על מתכנתים, אבל מודפס משהו מוזר.

```python
response = client.models.generate_content(
    model="gemini-2.5-flash", contents="Tell me a short joke about programmers")
print(response)
```

קראו את הפלט. איפה הטקסט של התשובה? תקנו שורה אחת, והריצו שוב. האם קיבלתם אותה בדיחה? (במודל אמיתי — כנראה לא.)

## 2. משימה 1: פעולה עוטפת

כתבו את הפעולה `ask_the_ai(my_prompt)`: היא שולחת את `my_prompt` למודל **ומחזירה** (`return`) את הטקסט — בלי `print` בתוכה. בתוכנית הראשית קראו לה עם `"What is the distance between the Earth and the Moon?"`, שמרו את התוצאה במשתנה והדפיסו אותו.

## 3. משימה 2: פרומפט דינמי

קלטו שם של סבתא ותכונה טובה שלה, בנו פרומפט עם f-string, **הדפיסו את הפרומפט**, שלחו אותו עם `ask_the_ai` והדפיסו את התשובה.

```text
Grandma's name: Sara
A good trait of hers: kind
Prompt: Write a short birthday greeting for Sara, who is a very kind grandmother.
```

## 4. משימה 3: קינוח החלומות

בלולאת `while` קלטו מרכיבים עד שהמשתמש מקליד `done`, והוסיפו כל אחד למחרוזת `all_ing` (עם פסיק ורווח אחריו). **אחרי הלולאה** (בלי הזחה!) בנו פרומפט שמבקש קינוח מטורף מהמרכיבים, שלחו **פעם אחת** והדפיסו את התשובה. בסוף הדפיסו `Calls sent:` ואת `client.models.calls` (רק בגרסת הכיתה).

```text
Calls sent: 1
```
