# יחידה 4.2 – להכניס בינה לקוד (API)

כיתה ח׳ · AI + Python B · **פרויקטון "יום מאוזן"**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> קודם אוספים את כל הנתונים, ורק אחרי הלולאה שולחים ל-AI קריאה **אחת**. ה-AI מקבל פרומפט ברור שנבנה עם f-string, ומחזיר הצעה שאנחנו בודקים.

## דף עזר

```python
def calc_time_today(start, end):
    return end - start

all_tasks = ""
task_name = input("Enter a task (or done to finish): ")
while task_name != "done":
    task_time = float(input(f"How many hours will {task_name} take? "))
    all_tasks += f"{task_name} ({task_time} hours), "
    task_name = input("Enter another task (or done to finish): ")

# הלולאה הסתיימה: עכשיו בונים פרומפט ושולחים פעם אחת
prompt = f"I have these tasks: {all_tasks} ..."
result = ask_the_ai(prompt)
```

<div dir="rtl">

פרומפט טוב כולל: **הקשר** (מי אני), **משימה** (מה לבנות), **נתונים** (השעות והמטלות) ו**תוצר רצוי** (למשל רשימה קצרה של בלוקי זמן). בודקים את הפרומפט בצ'אט לפני הקוד, ולא כותבים בו מידע אישי.

</div>

> [!NOTE]
> בקובץ ההתחלה יש **אזור A** (לקוח מדומה עם תשובות קבועות) ואת הפעולה `ask_the_ai` מהמפגש הקודם. לא נוגעים באזור A.

## 1. חימום: משתנה שלא קיים

הריצו את `BalancedDay_Starter.py`. התוכנית נעצרת עם שגיאה. קראו אותה, מצאו את הטעות ותקנו.

```python
today_time = sleep_hour - home_hour
prompt = f"I have {time_today} hours today. Build me a balanced schedule that starts at {home_hour}."
```

איך אפשר לגלות טעות כזו לפני ששולחים ל-AI? (רמז: מדפיסים את הפרומפט.)

## 2. שלב 1: כמה שעות יש לנו?

קלטו `home_hour` ו-`sleep_hour` (מספרים שלמים). כתבו פעולה `calc_time_today(start, end)` שמחזירה את מספר השעות, וקראו לה. הדפיסו: `You have 8 hours this afternoon.`

## 3. שלב 2: אוספים מטלות

לולאת `while` עד שהמשתמש מקליד `done`. בכל סיבוב: שם מטלה ואחריו מספר שעות (`float(input(...))`), והוספה ל-`all_tasks` עם `+=`. שורת ה-`input` הבאה היא **השורה האחרונה** בלולאה. הדפיסו את `all_tasks` כדי לבדוק.

```text
homework (2.0 hours), sport (1.5 hours), 
```

## 4. שלב 3: הפרומפט והקריאה היחידה

תכננו את הפרומפט בצ'אט. **אחרי הלולאה** בנו אותו עם f-string מ-`all_tasks`, `today_time`, `home_hour` ו-`sleep_hour`, הדפיסו אותו, קראו ל-`ask_the_ai` **פעם אחת** והדפיסו את הלו"ז. בסוף הדפיסו `Calls sent:` ואת `client.models.calls` (בגרסת הכיתה בלבד) — צריך לצאת 1.

## 5. פיצ'רים מתקדמים (בוחרים אחד או שניים — או רעיון משלכם)

<div dir="rtl">

1. לבקש מה-AI אימוג'י מתאים לכל מטלה.
2. לתת למשתמש לבחור שפה (עברית / אנגלית) ולשלב אותה בפרומפט.
3. מטלה בשם קצר מ-3 אותיות לא נוספת (`len`).
4. `total_task_time += task_time`; אם המטלות תופסות יותר שעות מהיום — לא קוראים ל-AI, אלא מדפיסים אזהרה.
5. לבקש משפט מוטיבציה קצר לכל מטלה.
6. סיכום באחוזים: `task_percent = total_task_time / today_time * 100`.
7. פרטיות: מטלה שמכילה `password`, `phone` או `address` לא נוספת (עם אזהרה).

</div>
