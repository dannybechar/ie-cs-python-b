## Official scope
List, Tuple, Set, Dictionary, compound structures such as list of
lists/list of tuples, search/sum/count/min/max and related algorithmic
patterns, creating a new data structure derived from an existing one,
solving algorithmic problems using data structures.

## Continuity bridge
Because the new Grade 8 Part B explicitly teaches List but not Tuple/Set,
List is treated as review while Tuple and Set receive a compact first
teaching rather than being assumed as prior knowledge. The bridge is
absorbed into the official 12h allocation (Meeting 1).

## Meeting 1 — Choose the Structure (List/Tuple/Set bridge)
Review List; introduce Tuple (fixed records, indexing, immutability) and
Set (uniqueness, membership, add/remove, no indexing). Protected task:
Event Sign-up, using all three structures for distinct roles.

## Meeting 2 — Search the Collection (algorithm patterns → Dictionary)
First 45 min completes the official 2h simple-structure algorithm practice
(manual search/count/sum/max patterns). Second 45 min is the official 1h
Dictionary theory block: why positional lookup is awkward, key/value model.
Protected task: Score Book.

## Meeting 3 — Key → Value (Dictionary lab)
Completes the 2 practical hours of the official 3h Dictionary block:
mutation (add/update/delete keys), safe membership-guarded lookup.
Protected task: Inventory Tracker.

## Meeting 4 — Data Inside Data (compound structures)
Second and final 1h theory block of the unit: outer collection → record →
field, using list-of-lists and list-of-tuples as the Core examples.
Protected task: Tournament Results.

## Meeting 5 — Scan Nested Data (algorithms on records)
Completes the 2 practical hours of the complex-structure block, then
begins the final 3h algorithm-on-complex-data block: manual count/sum/max
over record fields, deriving a new collection. Protected task: Class Stats.

## Meeting 6 — Representation Challenge (Unit 1 checkpoint)
Completes the final 2h of the complex-data algorithm block. One coherent
dataset requiring List, Set and Dictionary together, manual aggregation,
and a representation rationale. Protected task: Reading Challenge Analyzer.

## Exit criteria
The student can explain the purpose of List/Tuple/Set/Dictionary, choose a
suitable representation, use core operations, solve algorithmic problems
over simple and compound structures, and derive a new structure from
existing data.

## Depth boundary
Core does not expand automatically into: advanced collections, generators,
comprehensions as a required technique, formal data-structure complexity
analysis.
