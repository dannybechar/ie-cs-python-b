## דף עזר

```python
def find_max(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest


def print_digits(number):
    while number > 0:
        print(number % 10)
        number = number // 10
```

<div dir="rtl">

- `number % 10` — הספרה האחרונה. `number // 10` — המספר בלי הספרה האחרונה.
- משתנה שנבנה בלולאה מתחיל **לפני** הלולאה: `0` לסכום או למונה, `1` למכפלה.

</div>
