דף עזר

def find_max(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest


def print_digits(number):
    while number > 0:
        print(number % 10)
        number = number // 10
  • number % 10 — הספרה האחרונה. number // 10 — המספר בלי הספרה האחרונה.
  • משתנה שנבנה בלולאה מתחיל לפני הלולאה: 0 לסכום או למונה, 1 למכפלה.

    discount = price * percent / 100

9. משימה 8: calculate_gift

לקוח מועדון מקבל תלוש שי אם היקף הקניות החודשי שלו (monthly) גדול מ-1,200 ש״ח: 50 ש״ח לכל שנת חברות אם יש לו פחות מ-8 שנות חברות (years), ו-100 ש״ח לכל שנה אם יש לו 8 שנים ומעלה. אחרת הוא לא זכאי והפעולה מחזירה 0.

כתבו calculate_gift(years, monthly) שמחזירה את סכום התלוש. בדקו: (5, 1500) ← 250 · (10, 1500) ← 1000 · (10, 1000) ← 0.
