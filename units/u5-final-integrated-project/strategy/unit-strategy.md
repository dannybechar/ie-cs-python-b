# Unit 5 — Final Integrated Project

**12h = 2 Theory + 10 Practice = 6 double meetings**
Source: [`python-c.pdf`](../../../docs/ministry-source/python-c.pdf) Unit 5. Framing: [`../../../docs/annual-strategy.md`](../../../docs/annual-strategy.md).

**Build status:** ❌ not started.

## Official scope
A personal project such as a game, simulation, or learning application,
implemented in Python using an object-oriented approach and integrating
the year's topics: data structures, classes, objects, mouse/keyboard
events, sound, animation, wait and/or timer.

## Required process
Official guidance requires: personal project definition, teacher-guided
requirements, mandatory and extension milestones, a schedule for
milestones, a planning document, code documentation/comments, checking
each milestone against prior requirements, debugging, a final project
document, user instructions, reflection, and presentation/oral explanation.

## Meeting 1 — Knowledge + Lab — Scope & architecture
Define project, must-have vs. extension, data structures, classes, events,
milestone plan. Deliverable: approved project plan.

## Meeting 2 — Knowledge + Lab — Implementation architecture
Map objects/classes, map events to handlers, map data structures, define
first working milestone, debugging/testing discipline.

## Meeting 3 — Lab + Lab — Build Milestone 1
Core data model, classes, first working interaction.

## Meeting 4 — Lab + Lab — Build Milestone 2
Event integration, game/application behavior, testing against previous
requirements.

## Meeting 5 — Lab + Lab — Complete, debug, document
Animation/sound/timer where needed, bug fixing, comments, user
instructions, final documentation.

## Meeting 6 — Lab + Lab — Presentation & defense
Demonstrate project, explain architecture/data structures/classes/objects/
event flow, reflect on bugs, decisions and limitations.

## Core vs. extension
**Mandatory:** at least one meaningful data structure, class/object use,
meaningful event handling, working integrated application, documentation
and explanation.

**Extension:** richer sound/animation, additional event types, more
sophisticated game logic, more complex compound structures, additional
classes where justified.

Technical spectacle must not replace understanding.
