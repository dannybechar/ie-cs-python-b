# יחידה 7.1 – רשימות

כיתה ח׳ · AI + Python B · **מהי רשימה? יוצרים, ניגשים, חותכים**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> רשימה מחזיקה אוסף סדור ודינמי של ערכים תחת שם אחד — מאונדקסת מ-0, וניתנת לשינוי אחרי שנוצרה. חיתוך `[start:stop:step]` נותן רשימה **חדשה**.

## דף עזר

```python
scores = [72, 84, 65]          # רשימה עם ערכים
empty = []                     # רשימה ריקה (אפשר גם list())
print(len(scores))             # 3
print(scores[0])               # 72
print(scores[-1])              # 65
scores[1] = 90                 # עדכון במקום
print(90 in scores)            # True
print(scores + [50])           # [72, 90, 65, 50] - רשימה חדשה

my_list = [25, 20, 21, 24, 21, 24, 21, 16, 23]
print(my_list[:5])             # [25, 20, 21, 24, 21]
print(my_list[2:5])            # [21, 24, 21]   (הסוף לא נכלל)
print(my_list[2:9:3])          # [21, 24, 23]
print(my_list[::-1])           # הרשימה הפוכה
```

<div dir="rtl">

- `values[2]` (ערך במיקום) ו-`2 in values` (האם הערך קיים בכלל) שואלות שתי שאלות שונות.
- האינדקס האחרון הוא `len(values) - 1`. אינדקס גדול מזה גורם ל-`IndexError`.
- רשימה היא mutable — אפשר לשנות אותה אחרי שנוצרה. חיתוך ו-`+` יוצרים רשימה חדשה ולא משנים את המקור.

</div>

## 1. חימום: הושווה, לא הושם

פתחו את `Lists_Starter.py`.

```python
scores = [60, 70, 80]
scores[1] == 75
print(scores)
```

חזו `[60, 75, 80]`, הריצו — מקבלים `[60, 70, 80]` ללא שינוי. מדוע? תקנו סימן אחד.

## 2. משימה 1: דוח תוצאות AI

כתבו `ai_report(scores)` — מדפיסה: כמה ציונים, הציון הראשון, הציון האחרון, והאם 100 נמצא ביניהם. בדקו על `[81, 24, 67, 91]`.

```text
Number of tests: 4
First score: 81
Last score: 91
Contains perfect score: False
```

## 3. משימה 2: עדכון עם בדיקת גבולות

כתבו `update_score(scores, index, new_value)` — אם `index` הוא מיקום תקין, מעדכנים ומחזירים `True`; אחרת מדפיסים `"Invalid index"` ומחזירים `False`. בדקו על `[60, 70, 80]` עם אינדקס 1 (תקין) ועם אינדקס 5 (לא תקין).

## 4. משימה 3: דוח חיתוכים

כתבו `slice_report(values)` שמדפיסה, כל פריט בשורה משלו עם כותרת: הרשימה כולה, חמשת הפריטים הראשונים, הפריטים ממקום 2 עד 5 (לא כולל), כל פריט שלישי החל ממקום 2, והרשימה הפוכה. בדקו על `[25, 20, 21, 24, 21, 24, 21, 16, 23]`.

```text
Every third, from index 2: [21, 24, 23]
```

(זו אחת מחמש השורות הצפויות.)

## 5. אם נשאר זמן: חיבור ו-list()

כתבו `combine(first, second)` שמחזירה רשימה חדשה משני הרשימות (עם `+`). הדפיסו אותה ואת אורכה, והראו שהמקור לא השתנה. אחר כך הדפיסו `list("cat")` והסבירו מה `list()` עשתה.
