def linear_search(values, target):
    for index in range(len(values)):
        if values[index] == target:
            return index
    return -1

2. משימה 1: חיפוש ברשימה ממוינת

כתבו linear_search_sorted(values, target) שעוצרת מוקדם: ברשימה ממוינת, ברגע ש-values[index] כבר לא קטן מ-target, אין טעם להמשיך. בדקו על [10, 20, 35, 50, 80] עם 35 ועם 40. אחר כך הריצו .index(35) ו-.index(40) על אותה רשימה. מה ההבדל כשהערך חסר?

תחרות ריצה (מתוך מאגר השאלות 14.4, שאלה 10): best היא רשימה ממוינת של תוצאות הריצה הטובות ביותר בבית הספר (קטן = טוב). כתבו position_in_ranking(best, result): אם result שווה לאחת התוצאות — החזירו את האינדקס שלה; אחרת החזירו את האינדקס של התוצאה הראשונה שגדולה ממנו (עצרו ברגע שמצאתם!); אם אין גדולה ממנו, החזירו len(best). בדקו על [10, 20, 35, 50, 80] עם 35 (מקום 2), 40 (מקום 3), 5 (מקום 0) ו-99 (מקום 5).

3. משימה 2: מספר טלפון חדש

חברת טלפונים נותנת לכל לקוח מספר חדש: קידומת מ-["050", "052", "053", "054"], מקף ו-7 ספרות אקראיות, למשל 052-8819853.

א. random_number(prefixes) — מחזירה מספר אקראי (random.choice, random.randint, str).

ב. is_special(number, special) — True כשהמספר ברשימת המיוחדים, או שהספרה "5" מופיעה בשבע הספרות יותר מפעם אחת, או ששבע הספרות הן רצף עולה או יורד. מספרים מיוחדים לא נותנים ללקוחות.

ג. new_phone_number(taken, special) — מחזירה מספר שאינו ברשימת התפוסים ואינו מיוחד.

ד. בנו בלולאה רשימה של 10 מספרים שונים והדפיסו אותה.

4. משימה 3: הפרויקט "מנתח ניסויי AI"

כתבו תוכנית שקולטת ציוני דמיון עם input() עד שמוזן -1 (הזקיף — לא נשמר) ושומרת רק ציונים מ-0 עד 100 (אחרת מדפיסה "Invalid score"). אחר כך התוכנית מדפיסה:

  • את הרשימה המקורית ועותק ממוין שלה (המקור לא משתנה)
  • ממוצע, מינימום ומקסימום
  • קלט של סף, וכמה ציונים שווים לסף או גבוהים ממנו
  • קלט של ציון לחיפוש, ואת מקומו ברשימה הממוינת (-1 אם אין)

כל חלק הוא פעולה קטנה שבדקתם לבד קודם. אם אין ציונים תקינים — "No valid scores" וללא חלוקה באפס. בדקו על:

120, -5, 80, -1        (רק 80 נשמר)
-1                     (אין נתונים)
70, 70, 80, -1         (כפילויות)

NOTE

ציון דמיון הוא המספר של מודל אחד, לא הסתברות ולא עובדה. כשמסבירים את התוצאה, כותבים זאת.

5. מאגר שאלות לבחינה (אם נשאר זמן — בחרו אחת)

א. (14.4 שאלה 3) shift_right(values) — מזיזה כל ערך מקום אחד ימינה, והאחרון הופך לראשון: [1, 2, 3, 4] ← [4, 1, 2, 3].

ב. (14.4 שאלה 8) is_permutation(values) — True אם ברשימה בגודל N כל מספר מ-1 עד N מופיע בדיוק פעם אחת: [2, 4, 5, 1, 3] כן, [2, 4, 4, 1, 3] לא.

ג. (14.4 שאלה 9) improved(times) — זמני ריצה: True אם כל ריצה מהירה (קטנה) יותר מהריצה שלפניה.

ד. (14.4 שאלה 4) מצאו את שתי הטעויות בפעולה strictly_ascending שבקובץ ההתחלה: היא אמורה לבדוק אם רשימה בסדר עולה ממש (בלי שכנים שווים).
