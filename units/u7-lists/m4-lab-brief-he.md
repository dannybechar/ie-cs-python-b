> [!IMPORTANT]
> מונה גדל רק כשהתנאי מתקיים. מקסימום מתחילים מערך **אמיתי** מהרשימה (`values[0]`), לא מ-0. כשכל הנתונים ברשימה שטוחה אחת (שם, מחיר, שם, מחיר…), המקום קובע מה הפריט: מקום זוגי הוא שם ומקום אי-זוגי הוא מחיר.

## דף עזר

```python
count = 0
for value in values:
    if value > 50:
        count += 1            # גדל רק כשהתנאי מתקיים

largest = values[0]           # לא 0!
for value in values:
    if value > largest:
        largest = value

menu = ["milk", 15, "bread", 10, "cornflakes", 20, "eggs", 18]
for index in range(len(menu)):
    if index % 2 == 1:        # מקום אי-זוגי: מחיר
        print(menu[index - 1], menu[index])   # השם נמצא לפני המחיר

print(menu[0::2])             # כל השמות
print(menu[1::2])             # כל המחירים
```

<div dir="rtl">

א. **שפת Robber** — `robber(text)`: כל אות שאינה אות ניקוד (`a e i o u`) מוכפלת וביניהן `o`; אותיות הניקוד והרווח נשארים. `"cat"` הופך ל-`"cocatot"`.
