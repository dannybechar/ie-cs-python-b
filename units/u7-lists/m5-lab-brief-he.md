```python
def linear_search(values, target):
    for index in range(len(values)):
        if values[index] == target:
            return index
    return -1
```

## 1. חימום: נמצא במקום 0 ודווח כלא נמצא

פתחו את `Analyzer_Starter.py`.

```python

if linear_search(scores, 81):
    print("Found")
else:
    print("Not found")
```

חזו `Found`. הריצו — מתקבל `Not found`. למה? תקנו את אופן בדיקת התוצאה.

## 2. משימה 1: חיפוש ברשימה ממוינת

כתבו `linear_search_sorted(values, target)` שעוצרת מוקדם: ברשימה **ממוינת**, ברגע ש-`values[index]` כבר לא קטן מ-`target`, אין טעם להמשיך. בדקו על `[10, 20, 35, 50, 80]` עם 35 ועם 40. אחר כך הריצו `.index(35)` ו-`.index(40)` על אותה רשימה. מה ההבדל כשהערך חסר?

## 4. משימה 3: הפרויקט "מנתח ניסויי AI"

כתבו תוכנית שקולטת ציוני דמיון עם `input()` עד שמוזן `-1` (הזקיף — לא נשמר) ושומרת רק ציונים מ-0 עד 100 (אחרת מדפיסה `"Invalid score"`). אחר כך התוכנית מדפיסה:

<div dir="rtl">

- את הרשימה המקורית ועותק **ממוין** שלה (המקור לא משתנה)
- ממוצע, מינימום ומקסימום
- קלט של סף, וכמה ציונים שווים לסף או גבוהים ממנו
- קלט של ציון לחיפוש, ואת מקומו ברשימה הממוינת (`-1` אם אין)

</div>

כל חלק הוא פעולה קטנה שבדקתם לבד קודם. אם אין ציונים תקינים — `"No valid scores"` וללא חלוקה באפס. בדקו על:

```text
120, -5, 80, -1        (רק 80 נשמר)
-1                     (אין נתונים)
70, 70, 80, -1         (כפילויות)
```

> [!NOTE]
> ציון דמיון הוא המספר של מודל אחד, לא הסתברות ולא עובדה. כשמסבירים את התוצאה, כותבים זאת.
