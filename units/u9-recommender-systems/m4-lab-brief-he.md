## 2. חימום: סופרים לכיוון ההפוך

פתחו את `Bubble_Starter.py`, חזו מה יודפס, והריצו.

```python
def count_related(feed, topic):
    count = 0
    for card in feed:
        if card != topic:
            count += 1
    return count


print(count_related(["space", "space", "cooking", "space", "sports"], "space"))
```

<div dir="rtl">

חזו `3` (שלושה כרטיסים על `"space"`). מקבלים `2`. תקנו שורה אחת.

</div>

## 3. משימה 1: simulate_feed_round(topic, other_topics, round_number)

<div dir="rtl">

מודל צעצוע של פיד בן 5 כרטיסים. המשתמש ממשיך לצפות ב-`topic`, ולכן בכל סיבוב יש בפיד עוד ממנו: `related = round_number + 1`, אבל לא יותר מ-4. כרטיסי `topic` באים ראשונים, והמקומות הנותרים מתמלאים מ-`other_topics` אחד אחרי השני (וחוזרים להתחלה). מחזירה רשימה של 5 נושאים. בדקו:

</div>

```python
other_topics = ["cooking", "sports", "art"]
print(simulate_feed_round("space", other_topics, 0))
print(simulate_feed_round("space", other_topics, 2))
print(simulate_feed_round("space", other_topics, 6))
```

```text
['space', 'cooking', 'sports', 'art', 'cooking']
['space', 'space', 'space', 'cooking', 'sports']
['space', 'space', 'space', 'space', 'cooking']
```
