## 3. חימום: נספר לכיוון ההפוך

פתחו את `Bubble_Starter.py`.

```python
def count_related(recommendations, topic):
    count = 0
    for rec in recommendations:
        if rec != topic:
            count += 1
    return count


print(count_related(["space", "space", "cooking", "space", "sports"], "space"))
```

חזו `3` (שלושה מתוך חמישה קשורים ל-`"space"`), הריצו — מקבלים `2`. התנאי סופר לא-קשורים במקום קשורים. תקנו: `==` במקום `!=`.

## 4. משימה 1: simulate_feed_round(current_topic, other_topics, round_number)

מדמה את כלל הכרטיסים: מחזירה רשימה של 3 המלצות — שתי עותקים של `current_topic`, ונושא "אחר" אחד, נבחר באופן קבוע (לא אקראי) כ-`other_topics[round_number % len(other_topics)]`.

## 5. משימה 2: run_bubble_experiment(start_topic, other_topics, rounds)

חוזרת על `simulate_feed_round` `rounds` פעמים, מדפיסה ואוספת `count_related(...)` בכל פעם. בדקו שהמספר הקשור לעולם לא יורד מתחת ל-2 מתוך 3.

## 6. מושגים, החלטות קוד וערכת שליטה

בועת סינון לעומת תיבת תהודה; כלכלת הקשב (מה המערכת ממקסמת? מי מרוויח מזמן צפייה ארוך יותר?); ואז ההחלטות בקוד שלנו:

<div dir="rtl">

| החלטה בקוד שלנו | השפעה אפשרית |
|---|---|
| בחירה בתאום יחיד | המלצה רגישה מאוד לאדם אחד |
| דרישה לשני דירוגים משותפים בלבד | המלצה מהירה על בסיס מידע חלש |
| המלצה רק על פריט שהציון שלו 3 | לא מבטיחה גיוון |

</div>

בחרו לפחות שני כלים מערכת שליטה בפיד לניסיון או דיון (למשל "לא מעניין", מחיקת היסטוריה חד-פעמית, חיפוש יזום במקורות מגוונים).
