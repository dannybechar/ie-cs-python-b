> [!WARNING]
> בסקר לא אוספים שם, דוא"ל, טלפון, כיתה או תמונה. משתמשים בכינוי או במספר. בוחרים נושא נייטרלי בלבד, והמורה בודק את הסקר לפני ששולחים.

> [!IMPORTANT]
> מערכת המלצה לא קוראת מחשבות — היא לומדת מההתנהגות שלנו או מאנשים שדומים לנו. כדי שהקוד יוכל להשוות אנשים, כולם עונים באותה סקאלה סגורה: `V` אהבתי, `X` לא אהבתי, `0` לא מכיר/ה. **רק אותיות גדולות באנגלית.**

## דף עזר

```text
מבוססת תוכן:   מה אהבתי ← מאפייני הפריט ← פריטים דומים
מבוססת משתמשים: התשובות שלי ← אנשים עם תשובות דומות ← מה הם אהבו ואני לא מכיר/ה
```

<div dir="rtl">

סקאלה: `V` — אהבתי, `X` — לא אהבתי, `0` — לא מכיר/ה. נקודת דמיון: שתי תשובות **זהות** ושאינן `0`.

</div>

## 1. חימום: הכול נהיה "לא מכיר"

פתחו את `SurveyData_Starter.py`, חזו מה יודפס, והריצו.

```python
def describe_answer(answer):
    if answer == "V":
        return "liked"
    elif answer == "X":
        return "disliked"
    else:
        return "don't know"


print(describe_answer("0"))
print(describe_answer("v"))
```

<div dir="rtl">

חזו `don't know` ואחריו `invalid answer`. הריצו — מקבלים `don't know` פעמיים. מי "בולע" את התשובה השגויה? תקנו כך ש-`0` יחזיר `don't know` ותשובה לא חוקית תחזיר `invalid answer`.

</div>

## 2. משימה 1: is_valid_answers(answers)

<div dir="rtl">

התשובות של אדם אחד הן מחרוזת, תו אחד לכל פריט. כתבו פעולה שמחזירה `True` רק אם **כל** תו הוא `V`, `X` או `0`. בדקו:

```python
print(is_valid_answers("VX0XV"))   # True
print(is_valid_answers("VX0xV"))   # False
print(is_valid_answers("VX5XV"))   # False
```

## 4. בונים סקר

<div dir="rtl">

בזוגות, ב-Google Forms:

1. בחרו נושא נייטרלי (מוזיקה, סדרות, משחקים, טיולים, אוכל, ספורט) — לא בריאות, פוליטיקה, דת או משהו אישי.
2. כתבו 6–10 פריטים בשמות ברורים.
3. לכל פריט אותן שלוש אפשרויות: `V`, `X`, `0`. מקרא אחד בראש הטופס.
4. שאלה ראשונה: כינוי או מספר (לא שם).
5. בהגדרות: לא אוספים כתובות דוא"ל ולא דורשים כניסה.

</div>
