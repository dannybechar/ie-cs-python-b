## דף עזר

```text
המלצה מבוססת תוכן:    אהבתי פריט ← מאפייני הפריט ← פריטים בעלי מאפיינים דומים
המלצה מבוססת משתמשים: הדירוגים שלי ← משתמש דומה ← פריט שהוא אהב ואני לא מכיר/ה
```

<div dir="rtl">

סקאלת הדירוג: `0` — לא מכיר/ה, `1` — לא אוהב/ת, `2` — ניטרלי, `3` — אוהב/ת.

</div>

## 2. חימום: המשמעות של 0

פתחו את `SurveyData_Starter.py`.

```python
def describe_rating(value):
    if value == 0:
        return "not liked"
    elif value == 1:
        return "disliked"
    elif value == 2:
        return "neutral"
    elif value == 3:
        return "liked"


print(describe_rating(0))
```

חזו `"don't know"`, הריצו — מקבלים `"not liked"`. הפונקציה מבלבלת "לא מכיר/ה" עם "לא אוהב/ת" — זה ישבור את חישוב הדמיון ביחידה 9.2. תקנו.
