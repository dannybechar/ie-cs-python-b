# יחידה 5.1 – מחרוזות

## תסריט לשיעור פרונטלי: תעודת זהות לרובוט

קובץ הקוד: [`m1-live-program.py`](m1-live-program.py). בונים אותו שלב אחרי שלב על המקרן (Thonny): שאלה לכיתה ← דיון ← כתיבת השורות ← הרצה ← קריאת התוצאה. הקלט בהרצות: `ROBOT` ו-`7`.

> [!IMPORTANT]
> **הבעיה (להקריא):** חברה רוצה מכונה שמפיקה תעודת זהות לרובוט. המשתמש מקליד שם וגיל. התוכנית מדפיסה כרטיס ממוסגר עם השם, אורכו, קוד של שתי אותיות (הראשונה והאחרונה) והגיל בשנה הבאה.

<div dir="rtl">

| שלב | שאלה לכיתה (חוזים קודם) | מקלידים | תוצאה ונקודת הוראה |
|---|---|---|---|
| 0 | תשובה של מודל שפה מגיעה לתוכנית — מה היא? | `answer = "Take a short break and drink water."`, `type`, `len`, `answer[0]` (ואז מוחקים) | `<class 'str'>`, `35`, `T`. תשובת AI היא מחרוזת שקוראים תו אחרי תו |
| 1 | מה `input` מחזירה — מילה או מספר? | `name = input(...)`, `print(type(name))`; `empty = ""`, `len(empty)` | `<class 'str'>`, `0`. הגרשיים אינם חלק מהמחרוזת; יש מחרוזת ריקה |
| 2 | כמה תווים ב-`ROBOT`? וב-`R2 D2`? | `print("Length:", len(name))` | `5` בשני המקרים: ספרות ורווח נספרים. חוזים `len(" ")`, `len("")`, `len("Python 3.12")` ← `1`, `0`, `11` |
| 3 | מי ראשון? מי אחרון? מה `name[2]`, `name[-2]`? (מציירים תיבות 0..4 למעלה ו-5-..1- למטה) | `first = name[0]`, `last = name[-1]`, הדפסות | `R T`, `B`, `O`. סופרים מ-0 מההתחלה ומ-1- מהסוף. תלמיד בוחר אינדקס בשם ארוך (`think big be bold`) |
| 4 | מה יקרה עם `name[len(name)]`? (הצבעה: עובד / שגיאה) | `print(name[len(name)])` | `IndexError: string index out of range`. מתקנים ל-`len(name) - 1` (או `-1`) |
| 5 | חוזים: מה שלוש שורות הכרטיס? | `border = "*" * (len(name) + 4)` ושלוש הדפסות | `+` מחבר, `*` חוזר. בצד: `"7" * 2` מול `7 * 2` ← `77` / `14` |
| 6 | מה יוצא מ-`first + last`? | `code = first + last` | `RT`. שגיאה מכוונת: `"Length: " + len(name)` ← `TypeError: can only concatenate str (not "int") to str`; תיקון עם `str(...)` |
| 7 | הגיל: מה ידפיס `age + age` עבור 7? | קודם `age = input(...)`, אחר כך `int(input(...))` ו-`age + 1` | `77` (הפתעה) ואז `8`. `input` תמיד מחזירה מחרוזת |
| 8 | נתקן את האות הראשונה: `name[0] = "r"` (הצבעה) | שורה אחת, הרצה, מחיקה | `TypeError: 'str' object does not support item assignment`. אפשר לקרוא תו, אי אפשר להחליף |
| 9 | קוד חוזר פעמיים — מה עושים? | `first_and_last`, `stars_for`, בדיקה `first_and_last("A")` | `RT`, `AA`, `*****`. תצוגה מקדימה של משימות 3–4 במעבדה |
| 10 | בדיקת יציאה עם `text = "MODEL"` | `text[1]`, `text[-1]`, `len(text)`, ואז `text[len(text)]` | `O`, `L`, `5`, `IndexError`. שמירה: `G8_U5_M1_Indices_<Name>.py` |

</div>

פלט צפוי להרצה מלאה עם `ROBOT` ו-`7`: הכרטיס הממוסגר (`*********` / `* ROBOT *` / `*********`), `Length: 5`, `Code: RT`, `Next year: 8`.

כל הודעות השגיאה נבדקו ב-Python 3.14. שורות `# ERROR DEMO` בקובץ מסומנות כהערה — מוציאים מהערה בזמן השיעור ומחזירים אחרי ההדגמה.
