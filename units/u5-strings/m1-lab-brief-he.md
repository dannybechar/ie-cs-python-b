# יחידה 5.1 – מחרוזות

כיתה ח׳ · AI + Python B · **מחרוזת היא רצף סדור של תווים**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

<div dir="rtl">

- בכל משימה כותבים קוד מתחת למשתנה, ומדפיסים את התשובה עם print. אחר כך משנים את ערך המשתנה ומריצים שוב.
- בזמן העבודה על משימה אחת אפשר לשים # לפני הקוד של המשימות האחרות.

</div>

> [!IMPORTANT]
> לכל תו במחרוזת יש מקום (אינדקס): מהתחלה סופרים מ-`0`, מהסוף סופרים מ-`-1`. האינדקס התקין האחרון הוא `len(text) - 1`.

## דף עזר

```python
text = "love :)"
print(len(text))          # 7 - גם רווחים וסימנים נספרים
print(text[0], text[-1])  # l )
```

```python
print("3" + "3")    # 33  - חיבור מחרוזות
print("3" * 3)      # 333 - כפל מחרוזת במספר שלם
print(int("12") + 1) # 13  - מחרוזת של ספרות הופכת למספר
print(str(12) + "3") # 123 - מספר הופך למחרוזת
```

<div dir="rtl">

- מחרוזת היא רצף של תווים, והיא משמשת בדרך כלל לביטוי מילים או משפטים.
- הגרשיים אינם חלק מהמחרוזת ורק מציינים מהיכן להתחיל ואיפה לסיים; פותחים וסוגרים באותו סימן.
- גרשיים כפולים וגרשיים בודדים הם אותו דבר: `"love"` ו-`'love'` שווים. אנחנו כותבים בכפולים.
- הקלט מ-`input()` הוא תמיד מחרוזת.

</div>

## 1. חימום: אינדקס אחד רחוק מדי

פתחו את `Indices_Starter.py`. הקוד אמור להדפיס את האות האחרונה של המילה.

```python
word = "ROBOT"
last_letter = word[len(word)]
print(last_letter)
```

חזו מה יקרה, הריצו וקראו את השגיאה. תקנו ביטוי אחד, בשתי דרכים: עם `len(word) - 1` ועם אינדקס שלילי. (כמו בטבלה "שתי דרכים" בשאלה 4 בדף העבודה: האות האחרונה של `"python"` היא `st[5]` וגם `st[-1]`.)

## 2. משימה 1: חוזים ובודקים

בקובץ מופיעות שמונה הוראות הדפסה (שאלות 1–2 מדף העבודה). **קודם** כתבו על הדף מה יודפס בכל אחת, ורק אחר כך הריצו והשוו.

## 3. משימה 2: מחרוזת או מספר

<div dir="rtl">

שני המשתנים הם מחרוזות של ספרות. כתבו קוד שמדפיס קודם את **סכום** המספרים, ואחר כך את שתי המחרוזות **מחוברות**.

</div>

```python
first = "12"
second = "30"
```

<div dir="rtl">

| ערך המשתנים | צפוי | בפועל |
|---|---|---|
| `first = "12"`, `second = "30"` | `42` ואחר כך `1230` | &nbsp; |
| `first = "5"`, `second = "5"` | `10` ואחר כך `55` | &nbsp; |

</div>

## 4. משימה 3: אינדקס חיובי ושלילי

<div dir="rtl">

כתבו קוד שמדפיס, כל תו בשורה משלו: את האות הראשונה פעמיים (פעם באינדקס חיובי ופעם בשלילי), את האות האחרונה פעמיים, ואת האות השלישית פעמיים. לכל תו יש **שתי דרכים** להגיע אליו, והמשימה מדפיסה את שתיהן.

</div>

```python
text = "PYTHON"
```

<div dir="rtl">

| ערך המשתנה | צפוי | בפועל |
|---|---|---|
| `text = "PYTHON"` | `P P N N T T` (כל אחת בשורה) | &nbsp; |
| `text = "ORANGE"` | `O O E E A A` (כל אחת בשורה) | &nbsp; |

</div>

## 5. משימה 4: הראשונה והאחרונה

<div dir="rtl">

כתבו קוד שמדפיס את האות הראשונה ואחריה את האות האחרונה.

</div>

```python
word = "ROBOT"
```

<div dir="rtl">

| ערך המשתנה | צפוי | בפועל |
|---|---|---|
| `word = "ROBOT"` | `RT` | &nbsp; |

</div>
