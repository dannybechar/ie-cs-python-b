# יחידה 5.1 – מחרוזות

כיתה ח׳ · AI + Python B · **מחרוזת היא רצף סדור של תווים**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> לכל תו במחרוזת יש מקום (אינדקס): מהתחלה סופרים מ-`0`, מהסוף סופרים מ-`-1`. האינדקס התקין האחרון הוא `len(text) - 1`.

## דף עזר

```python
text = "love :)"
print(len(text))          # 7 - גם רווחים וסימנים נספרים
print(text[0], text[-1])  # l )
```

```python
print("3" + "3")    # 33  - חיבור מחרוזות
print("3" * 3)      # 333 - כפל מחרוזת במספר שלם
print(int("12") + 1) # 13  - מחרוזת של ספרות הופכת למספר
print(str(12) + "3") # 123 - מספר הופך למחרוזת
```

- הגרשיים אינם חלק מהמחרוזת; פותחים וסוגרים באותו סימן.
- `input()` תמיד מחזירה מחרוזת.

## 1. חימום: אינדקס אחד רחוק מדי

פתחו את `Indices_Starter.py`. הקוד אמור להדפיס את האות האחרונה של המילה.

```python
word = "ROBOT"
last_letter = word[len(word)]
print(last_letter)
```

חזו מה יקרה, הריצו וקראו את השגיאה. תקנו ביטוי אחד, בשתי דרכים: עם `len(word) - 1` ועם אינדקס שלילי.

## 2. משימה 1: חוזים ובודקים

בקובץ מופיעות שמונה הוראות הדפסה (שאלות 1–2 מדף העבודה). **קודם** כתבו על הדף מה יודפס בכל אחת, ורק אחר כך הריצו והשוו.

## 3. משימה 2: מחרוזת או מספר

כתבו שתי פעולות. שני הפרמטרים הם מחרוזות של ספרות:

- `add_as_numbers(first, second)` — מחזירה את **סכום** המספרים.
- `join_as_text(first, second)` — מחזירה את שתי המחרוזות **מחוברות**.

בדיקה עם `"12"` ו-`"30"`: `42` ו-`"1230"`.

## 4. משימה 3: אינדקס חיובי ושלילי

כתבו `show_edges(st)`. עבור `"PYTHON"` היא מדפיסה, כל תו בשורה משלו: את האות הראשונה פעמיים (פעם באינדקס חיובי ופעם בשלילי), את האות האחרונה פעמיים, ואת האות השלישית פעמיים.

## 5. משימה 4: הראשונה והאחרונה

כתבו `first_and_last(word)` — מחזירה את האות הראשונה ואחריה את האות האחרונה. `"ROBOT"` ← `"RT"`, `"A"` ← `"AA"`.

## 6. אם נשאר זמן

כתבו `stars_for(word)` — מחזירה כוכבית אחת לכל תו במילה. `"hello"` ← `"*****"`.
