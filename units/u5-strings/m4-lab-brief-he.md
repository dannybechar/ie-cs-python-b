**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> כדי לפתור בעיית טקסט עוברים על התווים (או על המקומות) עם מונה, מקום שזוכרים, או מחרוזת חדשה שבונים עם `+=`. בכל משימה הטקסט נמצא במשתנה, והקוד מדפיס את התשובה עם `print`. כדי לבדוק ערך אחר – משנים את ערך המשתנה ומריצים שוב.

## דף עזר

```python
print(ord("a"), chr(100))        # 97 d  - אות הופכת למספר, ומספר לאות
print(chr(ord("c") + 1))         # d     - האות הבאה

for index in range(len(text)):   # כשצריך את המקום
    print(index, text[index])

print("guitar piano drums".split(" "))           # ['guitar', 'piano', 'drums'] - רשימה, רק מדפיסים
print("-".join("guitar piano drums".split(" ")))  # guitar-piano-drums
```

<div dir="rtl">

| משימה | כלי מתאים |
|---|---|
| לספור אות או רצף | לולאה ומונה, או `count` |
| המילה הראשונה | `find(" ")` וחיתוך |
| המילה האחרונה | לולאה שזוכרת את הרווח האחרון |
| בניית מחרוזת חדשה | לולאה ו-`+=` |
| אות ← מספר ← אות | `ord` ו-`chr` |

</div>

<div dir="rtl">

טיפ: הקובץ רץ מההתחלה עד הסוף. בזמן שעובדים על משימה אחת, שמים `#` לפני הקוד של המשימות האחרות (ב-Thonny: מסמנים את השורות ולוחצים Ctrl+3).

</div>

## 1. חימום: ה-or שתמיד נכון

פתחו את `Cipher_Starter.py`. הקוד בראש הקובץ אמור לספור רק את התנועות `a, e, i, o, u`.

```python
text = "sometimes you learn"
total = 0
for character in text:
    if character == "a" or "e" or "i" or "o" or "u":
        total += 1
print(total)                                   # אמור להיות 8
```

חזו, הריצו והסבירו למה מודפס מספר גדול מדי. תקנו שורה אחת.

## 2. משימה 1: המילה הראשונה והאחרונה

כתבו קוד שמדפיס את המילה הראשונה ואת המילה האחרונה בטקסט, עם רווח אחד ביניהן.

```python
text = "Cats and dogs are great friends"
```

<div dir="rtl">

| ערך המשתנה | צפוי |
|---|---|
| `text = "Cats and dogs are great friends"` | `Cats friends` |
| `text = "Hello"` | `Hello` |

</div>

## 3. משימה 2: ראשי תיבות

כתבו קוד שמדפיס את האותיות הראשונות של כל המילים. (רמז: אות ראשונה של מילה באה מיד אחרי רווח.)

```python
text = "American Standard Code Information Interchange"
```

<div dir="rtl">

| ערך המשתנה | צפוי |
|---|---|
| `text = "American Standard Code Information Interchange"` | `ASCII` |
| `text = "hello big world"` | `hbw` |

</div>

## 4. משימה 3: כמה פעמים `is`

כתבו קוד שמדפיס כמה פעמים מופיע הרצף `is` בטקסט – פעמיים:

<div dir="rtl">

- משימה 3a – בעזרת `count`.
- משימה 3b – בלי `count`.

</div>

```python
text = "this is his list"
```

<div dir="rtl">

| ערך המשתנה | צפוי |
|---|---|
| `text = "this is his list"` | `4` |
| `text = "mississippi"` | `2` |

</div>

למה בטקסט הראשון התשובה 4 ולא 1?

## 5. משימה 4: תנועות

כתבו קוד שמדפיס כמה פעמים מופיעה כל אחת מהאותיות `a, e, i, o, u`, כל אות בשורה משלה (`a: 1`). פעמיים: במשימה 4a עם `count`, ובמשימה 4b בלי `count` (מעבר אחד על הטקסט וחמישה מונים).

```python
text = "sometimes you learn"
```

הפלט הצפוי:

```text
a: 1
e: 3
i: 1
o: 2
u: 1
```

## 6. משימה 5: קוד האות הבאה

קודם הריצו את השורה הבאה וקראו את המספרים:

```python
for ch in "Hello": print(ord(ch), end=",")
```

אחר כך כתבו קוד שמדפיס את הטקסט כשכל אות הוחלפה באות הבאה באלף-בית, ו-`z` הופכת ל-`a`. תווים אחרים (רווח) נשארים. רק אותיות קטנות.

```python
text = "abcd"
```

<div dir="rtl">

| ערך המשתנה | צפוי |
|---|---|
| `text = "abcd"` | `bcde` |
| `text = "zoo"` | `app` |
| `text = "i like python"` | `j mjlf qzuipo` |

</div>

## 7. משימה 6: split ו-join

הריצו את שתי השורות שבהערה בקובץ וקראו את הפלט (`split` נותנת **רשימה** – בינתיים רק מדפיסים אותה). אחר כך כתבו קוד שמדפיס את הטקסט כשכל רווח הוחלף ב-`-`, בעזרת `split` ו-`join`. השוו ל-`replace`.

```python
text = "guitar piano drums"
```

הפלט הצפוי:

```text
guitar-piano-drums
```

## 8. בדיקת סיום היחידה

עבודה עצמית. בכל משימה כותבים קוד מתחת למשתנה, **ומדפיסים** את התשובה עם `print`. אחר כך משנים את ערך המשתנה ובודקים גם את המקרה המיוחד.

<div dir="rtl">

| משימה | המשתנה | מה הקוד מדפיס | בדיקה |
|---|---|---|---|
| האות האמצעית | `word = "robot"` | האות האמצעית; במילה באורך זוגי – שתי האמצעיות | `"robot"` ← `b` · `"python"` ← `th` · `"a"` ← `a` |
| הקצוות | `text = "I like to play drums"` | 4 התווים הראשונים ו-4 האחרונים; פחות מ-4 תווים ← `****` | `"I like to play drums"` ← `I lirums` · `"abc"` ← `****` |
| אות גדולה וקטנה | `text = "trust yourself"` | אות גדולה, קטנה, גדולה… רווח נשאר ואינו נספר | `"trust yourself"` ← `TrUsT yOuRsElF` |

</div>
