## דף עזר

```python
print(ord("a"), chr(100))        # 97 d  - אות הופכת למספר, ומספר לאות
print(chr(ord("c") + 1))         # d     - האות הבאה

for index in range(len(text)):   # כשצריך את המקום
    print(index, text[index])

print("guitar piano drums".split(" "))           # ['guitar', 'piano', 'drums'] - רשימה, רק מדפיסים
print("-".join("guitar piano drums".split(" ")))  # guitar-piano-drums
```

## 1. חימום: ה-or שתמיד נכון

פתחו את `Cipher_Starter.py`. הפעולה אמורה לספור רק את התנועות `a, e, i, o, u`.

```python
def count_vowels(text):
    total = 0
    for character in text:
        if character == "a" or "e" or "i" or "o" or "u":
            total += 1
    return total

print(count_vowels("sometimes you learn"))   # אמור להיות 8
```

חזו, הריצו והסבירו למה מודפס מספר גדול מדי. תקנו שורה אחת.

## 2. משימה 1: המילה הראשונה והאחרונה

`first_and_last_word(text)` — מחזירה את המילה הראשונה והמילה האחרונה עם רווח אחד ביניהן.
`"Cats and dogs are great friends"` ← `"Cats friends"`.

## 3. משימה 2: ראשי תיבות

`initials(text)` — מחזירה מילה מהאותיות הראשונות של כל המילים.
`"American Standard Code Information Interchange"` ← `"ASCII"`. (רמז: אות ראשונה של מילה באה מיד אחרי רווח.)

## 4. משימה 3: כמה פעמים `is`

- `count_is_a(text)` — בעזרת `count`.
- `count_is_b(text)` — בלי `count`.

`"this is his list"` ← `4`. למה לא 1?

## 5. משימה 4: תנועות

`print_vowels(text)` — מדפיסה כמה פעמים מופיעה כל אחת מהאותיות `a, e, i, o, u`, כל אות בשורה משלה (`a: 1`). נסו בשתי דרכים: עם `count`, ובלי `count` (מעבר אחד על הטקסט וחמישה מונים).

## 6. משימה 5: קוד האות הבאה

קודם הריצו `for ch in "Hello": print(ord(ch), end=",")`. אחר כך כתבו `next_letters(text)` — מחזירה טקסט שבו כל אות הוחלפה באות הבאה באלף-בית, ו-`z` הופכת ל-`a`. תווים אחרים (רווח) נשארים.
`"abcd"` ← `"bcde"`; `"zoo"` ← `"app"`; `"i like python"` ← `"j mjlf qzuipo"`.

## 7. משימה 6: split ו-join

הריצו את שלוש השורות שבקובץ וקראו את הפלט (`split` מחזירה **רשימה** — בינתיים רק מדפיסים אותה). אחר כך כתבו `dash_words(text)` שמחזירה את הטקסט כשכל רווח הוחלף ב-`-`, בעזרת `"-".join(text.split(" "))`. השוו ל-`replace`.

## 8. בדיקת סיום היחידה
