# שיעורים 7.1–7.2 – מחרוזות: מעבדה כתובה (45 דקות)
שם: ______________________  תאריך: ______________
כותבים את הקוד ביד, בתיבה שמשמאל. אחר כך מקלידים ב-Thonny, בודקים ומתקנים בצבע אחר. בסוף השיעור מגישים את הדף. כל סעיף ממשיך את הקודם.
## שאלה 1: שם קובץ (כ-22 דקות)
נתון שם הקובץ:
```python
file = "holiday_photo_2026.jpg"
```
**א.** הדפיסו את שם הקובץ בלי הסיומת, ואת הסיומת בנפרד. מצאו את מקום הנקודה וחתכו.
```text
Name: holiday_photo_2026
Extension: jpg
```
**ב.** ספרו כמה קווים תחתונים יש בשם, והדפיסו את המקום של הקו התחתון הראשון.
```text
Underscores: 2
First at: 7
```
**ג.** הדפיסו את השם כשכל הקווים התחתונים מוחלפים ברווח. אחר כך הדפיסו אותו כשרק הקו התחתון הראשון מוחלף במקף.
```text
holiday photo 2026.jpg
holiday-photo_2026.jpg
```
**ד.** אם בסעיף ב' יצא שאין קווים תחתונים, הדפיסו הודעה. אחרת, עברו על המקומות בלולאה והדפיסו את המקום של כל קו תחתון.
```text
Underscore at 7
Underscore at 13
```
## שאלה 2: קוד פריט (כ-22 דקות)
תוכנית שקוראת קוד של פריט במחסן, בצורה ארבע ספרות, מקף, ארבע אותיות, מקף, שנה.
**א.** קראו קוד. הוא חייב להכיל בדיוק 2 מקפים; כל עוד הוא לא תקין, הדפיסו הודעה ושאלו שוב.
```text
Code: 7340-ABCD
Need exactly 2 dashes
Code: 7340-ABCD-2026
```
**ב.** חתכו את הקוד לשלושה חלקים והדפיסו אותם. את המקף השני חפשו החל ממקום אחרי המקף הראשון.
```text
Part 1: 7340
Part 2: ABCD
Part 3: 2026
```
**ג.** הדפיסו את שלושת החלקים בסדר הפוך עם / ביניהם, ואחר כך את הקוד המקורי בלי המקפים.
```text
2026/ABCD/7340
7340ABCD2026
```
**ד.** הדפיסו גרסה מוסתרת: החלק הראשון, כוכבית במקום כל תו של החלק האמצעי, והחלק האחרון, עם מקפים. אחר כך הדפיסו את כל הקוד מהסוף להתחלה.
```text
7340-****-2026
Mirror: 6202-DCBA-0437
```
