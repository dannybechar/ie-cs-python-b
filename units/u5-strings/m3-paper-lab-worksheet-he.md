## שאלה 1: ניתוח הודעה (כ-22 דקות)
נתונה ההודעה:
```python
message = "Was it a car or a cat I saw?"
```
**א.** הדפיסו את ההודעה באותיות גדולות ואחר כך באותיות קטנות. הדפיסו גם אם היא מתחילה ב-was בלי הבדל בין אותיות גדולות לקטנות, ואם היא מסתיימת בסימן שאלה.
```text
WAS IT A CAR OR A CAT I SAW?
was it a car or a cat i saw?
Starts with was: True
Ends with a question mark: True
```
**ב.** עברו על כל התווים בלולאה אחת וספרו כמה אותיות, כמה ספרות וכמה תווים אחרים (רווחים וסימנים) יש בהודעה.
```text
Letters: 19
Digits: 0
Others: 9
```
**ג.** בנו מחרוזת חדשה שמכילה רק את האותיות של ההודעה, כולן באותיות קטנות, והדפיסו אותה.
```text
Letters only: wasitacaroracatisaw
```
**ד.** בנו את מחרוזת האותיות בסדר הפוך והדפיסו אותה. אם היא זהה למחרוזת המקורית, הדפיסו הודעה על כך.
```text
Backwards: wasitacaroracatisaw
The message reads the same both ways
```
## שאלה 2: קוד כרטיס (כ-22 דקות)
נתון קוד של כרטיס:
```python
code = "TK-2027-AB"
```
**א.** הדפיסו אם הקוד מתחיל ב-TK- ואם התו האחרון שלו הוא אות. הדפיסו גם את האורך.
```text
Starts with TK-: True
Ends with a letter: True
Length: 10
```
**ב.** הדפיסו כמה מקפים יש בקוד, ובאיזה מקום נמצא המקף הראשון.
```text
Dashes: 2
First dash at: 2
```
**ג.** חתכו את החלק שבין שני המקפים והדפיסו אותו כשנה. הדפיסו אם זו שנה תקינה: ארבע ספרות בדיוק.
```text
Year: 2027
Valid year
```
**ד.** בנו קוד נקי: בלי מקפים ובאותיות קטנות. הדפיסו אותו, וספרו בלולאה כמה ספרות יש בקוד.
```text
Cleaned: tk2027ab
Digits: 4
```
