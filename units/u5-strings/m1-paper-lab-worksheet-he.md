## שאלה 1: הפיכת מילה
כתבו קוד שמדפיס את המילה בסדר הפוך. בנו מחרוזת חדשה בלולאה.
```python
word = "STAR"
```
```text
RATS
```
## שאלה 2: ספירת אות
כתבו קוד שסופר כמה פעמים האות מופיעה במילה, ומדפיס את המספר.
```python
word = "BANANA"
letter = "A"
```
```text
3
```
## שאלה 3: מקפים בין התווים
כתבו קוד שמדפיס את המילה עם מקף בין כל שני תווים, בלי מקף בהתחלה ובסוף.
```python
word = "STAR"
```
```text
S-T-A-R
```
## שאלה 4: קוד זיהוי
כתבו קוד שמדפיס קוד: האות הראשונה, האות האחרונה, מקף ואורך המילה.
```python
word = "FALCON"
```
```text
FN-6
```
## שאלה 5: סיסמה
כתבו קוד ששואל סיסמה וממשיך לשאול עד שהיא באורך 6 תווים לפחות. אז הוא מדפיס הודעת ברכה.
```text

Welcome
```
