# יחידה 5.4 – מחרוזות: מעבדה כתובה (45 דקות)
שם: ______________________  תאריך: ______________
כותבים את הקוד ביד, בתיבה שמשמאל. אחר כך מקלידים ב-Thonny, בודקים ומתקנים בצבע אחר. בסוף השיעור מגישים את הדף. כל שאלה עומדת בפני עצמה, ואפשר לפתור אותן בכל סדר.
## שאלה 1: עיר
נתון שם של עיר. הדפיסו את האות הראשונה, את האות האחרונה, את האורך ואת האות האמצעית (האורך אי-זוגי).
```python
city = "jerusalem"
```
```text
First: j
Last: m
Length: 9
Middle: s
```
## שאלה 2: משפט
נתון משפט. הדפיסו כמה מילים יש בו (בלי לולאה), ואם יש יותר מ-4 מילים הדפיסו הודעה מתאימה.
```python
sentence = "the quick brown fox jumps"
```
```text
Words: 5
Long sentence
```
## שאלה 3: אות
נתונה אות קטנה באנגלית. הדפיסו את המספר שלה, את האות שלפניה, את האות שאחריה ואת המקום שלה באלף-בית (a היא 1).
```python
letter = "m"
```
```text
Number: 109
Previous: l
Next: n
Place in alphabet: 13
```
## שאלה 4: שם משתמש
בקשו מהמשתמש שם משתמש, ושאלו שוב כל עוד יש בו פחות מ-4 תווים. אחר כך הדפיסו ברכה עם האות הראשונה באות גדולה, ואת האורך.
```text
Username: ab
Too short, try again
Username: pixel7
Hello P
Length: 6
```
## שאלה 5: להקה
נתון שם של להקה. בנו ראשי תיבות באותיות גדולות (האות הראשונה, וכל אות שבאה מיד אחרי רווח) והדפיסו אותן.
```python
band = "red hot chili peppers"
```
```text
Initials: RHCP
```
## שאלה 6: תנועות
נתונה מילה. ספרו כמה תנועות (a, e, i, o, u) יש בה, והדפיסו גם כמה אותיות אחרות.
```python
word = "education"
```
```text
Vowels: 5
Consonants: 4
```
## שאלה 7: צופן הזזה
נתון טקסט. בנו טקסט מוצפן: כל אות זזה שתי אותיות קדימה באלף-בית, והרווח נשאר כמו שהוא. אין אותיות שחוזרות להתחלה בדוגמה הזאת.
```python
text = "hello world"
```
```text
Coded: jgnnq yqtnf
```
## שאלה 8: קוד מספרים
נתונה מילה. בנו קוד מספרים: המקום של כל אות באלף-בית, כשהמספרים מופרדים במקפים ואין מקף בסוף. הדפיסו גם את סכום המספרים.
```python
word = "snow"
```
```text
Number code: 19-14-15-23
Total: 71
```
