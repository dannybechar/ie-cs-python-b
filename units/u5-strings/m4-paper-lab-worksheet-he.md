## שאלה 1: שם של שיר (כ-22 דקות)
נתון שם של שיר:
```python
title = "moon light sonata"
```
**א.** הדפיסו את האות הראשונה, את האות האחרונה ואת האורך של השם. הדפיסו גם את האות האמצעית (האורך אי-זוגי, והאות האמצעית נמצאת במקום האורך לחלק ל-2 בחילוק שלם).
```text
First: m
Last: a
Length: 17
Middle: h
```
**ב.** ספרו כמה מילים יש בשם, בלי לולאה: מספר הרווחים ועוד אחד.
```text
Words: 3
```
**ג.** בנו ראשי תיבות באותיות גדולות: האות הראשונה של השם, וכל אות שבאה מיד אחרי רווח. הדפיסו אותן.
```text
Initials: MLS
```
**ד.** בנו שם חדש שבו כל מילה מתחילה באות גדולה, והדפיסו אותו. הדפיסו גם שם קצר: ראשי התיבות ואחריהם מספר המילים.
```text
Fixed title: Moon Light Sonata
Short name: MLS3
```
## שאלה 2: מילה סודית (כ-22 דקות)
נתונה מילה באותיות קטנות באנגלית:
```python
word = "bike"
```
**א.** הדפיסו את המספר של האות הראשונה במילה, ואת האות שבאה אחריה באלף-בית (בעזרת מספר ועוד אחד).
```text
Number of first letter: 98
Next letter: c
```
**ב.** בנו מילה סודית: הזיזו כל אות שלוש אותיות קדימה באלף-בית (ללא התחלה מחדש בסוף האלף-בית), והדפיסו אותה.
```text
Secret word: elnh
```
**ג.** בנו קוד מספרים: המקום של כל אות באלף-בית (האות הראשונה באלף-בית היא 1, השנייה 2, וכן הלאה), כשהמספרים מופרדים במקפים ואין מקף בסוף.
```text
Number code: 2-9-11-5
```
**ד.** פענחו את המילה הסודית מסעיף ב: הזיזו כל אות שלוש אותיות אחורה, והדפיסו. אם התוצאה זהה למילה המקורית, הדפיסו הודעה על כך.
```text
Decoded: bike
The code works
```
