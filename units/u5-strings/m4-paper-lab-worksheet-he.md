# יחידה 5.4 – מחרוזות: מעבדה כתובה (45 דקות)
שם: ______________________  תאריך: ______________
כותבים ביד בתיבה משמאל, מקלידים ב-Thonny ובודקים, מתקנים בצבע אחר ומגישים את הדף. כל שאלה עומדת בפני עצמה.
## שאלה 1: עיר
נתון שם של עיר. הדפיסו את האות הראשונה, האחרונה, האורך והאות האמצעית (האורך אי-זוגי).
```python
city = "jerusalem"
```
```text
First: j
Last: m
Length: 9
Middle: s
```
## שאלה 2: שם משתמש
בקשו שם משתמש, ושאלו שוב כל עוד יש בו פחות מ-4 תווים. אחר כך הדפיסו ברכה עם האות הראשונה באות גדולה, ואת האורך.
```text
Username: ab
Too short, try again
Username: pixel7
Hello P
Length: 6
```
## שאלה 3: להקה
נתון שם של להקה. הדפיסו כמה מילים יש בו (בלי לולאה), ובנו ראשי תיבות באותיות גדולות: האות הראשונה, וכל אות שבאה מיד אחרי רווח.
```python
band = "red hot chili peppers"
```
```text
Words: 4
Initials: RHCP
```
## שאלה 4: צופן הזזה
נתון טקסט. בנו טקסט מוצפן: כל אות זזה שתי אותיות קדימה באלף-בית, והרווח נשאר כמו שהוא. בדוגמה הזאת אין אות שחוזרת להתחלה.
```python
text = "hello world"
```
```text
Coded: jgnnq yqtnf
```
## שאלה 5: קוד מספרים
נתונה מילה. בנו קוד מספרים: המקום של כל אות באלף-בית (a היא 1), כשהמספרים מופרדים במקפים ואין מקף בסוף. הדפיסו גם את סכום המספרים.
```python
word = "snow"
```
```text
Number code: 19-14-15-23
Total: 71
```
