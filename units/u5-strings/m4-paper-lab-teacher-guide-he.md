# שיעורים 8.2–8.7 – מחרוזות: מדריך למורה – פתרונות מלאים
המעבדה הכתובה (45 דקות, חמש שאלות, דף אחד דו-צדדי) ושקופית האתגר למתקדמים. הקוד הוא פתרון מלא, ללא פעולות, כי הכיתה עוד לא למדה פעולות.

## איך משתמשים
- כל שאלה עומדת בפני עצמה. צד א: שאלות 1 ו-2. צד ב: שאלות 3 עד 5. לכל שאלה יש תיבת כלים לשימוש, בלי הפתרון.
- התלמידים כותבים ביד, מקלידים בתוכנה, בודקים, מתקנים בצבע אחר ומגישים את הדף. בודקים את התשובה הסופית, כולל התיקונים.
- זמן משוער לתלמיד ממוצע: 45 עד 55 דקות. אפשר להגיד שהשאלה האחרונה היא לבית אם לא הספיקו.
- תלמידים שסיימו מוקרנים לאתגר צופן המראה (העמוד האחרון במדריך). האתגר לא נבדק, והבונוס לפי שיקול דעתך.
- כל שאלה כוללת: פתרון מלא, פלט צפוי, פתרונות נוספים שמקבלים, טעויות נפוצות וניקוד.

## שאלה 1 – עיר (14 נקודות)
מדפיסים אות ראשונה, אחרונה, אורך ואות אמצעית של שם העיר (האורך אי-זוגי).
```python
city = "jerusalem"

print("First:", city[0])
print("Last:", city[-1])
print("Length:", len(city))
print("Middle:", city[len(city) // 2])
```
```text
First: j
Last: m
Length: 9
Middle: s
```
פתרונות נוספים שמקבלים:
```python
# also accepted
print("Last:", city[len(city) - 1])
print("Middle:", city[int(len(city) / 2)])
```
| סימן | קוד שגוי | סיבה |
|---|---|---|
| שגיאת סוג, מספר עשרוני | `city[len(city) / 2]` | חילוק רגיל נותן מספר עשרוני, צריך חילוק שלם |
| האות האמצעית שגויה | `city[len(city) / 2 + 1]` | שכחו שהספירה מתחילה ב-0 |

ניקוד: אות ראשונה 3, אחרונה 3, אורך 3, אות אמצעית 5.

## שאלה 2 – שם משתמש (14 נקודות)
קולטים שם משתמש ושואלים שוב כל עוד הוא קצר מדי. אחר כך מדפיסים ברכה עם האות הראשונה באות גדולה, ואת האורך.
```python
username = input("Username: ")
while len(username) < 4:
    print("Too short, try again")
    username = input("Username: ")
print("Hello", username[0].upper())
print("Length:", len(username))
```
```text
Username: ab
Too short, try again
Username: pixel7
Hello P
Length: 6
```
פתרונות נוספים שמקבלים:
```python
# also accepted
print("Hello", username.upper()[0])
```
| סימן | קוד שגוי | סיבה |
|---|---|---|
| הלולאה לא שואלת שוב | `if len(username) < 4:` | תנאי רגיל במקום לולאה |
| התוכנית לא נגמרת | הלולאה בלי קלט חדש | הערך לא משתנה, ולכן התנאי נשאר נכון |

ניקוד: קלט ראשון 3, תנאי הלולאה 4, קלט חוזר 3, אות גדולה 3, אורך 1.

## שאלה 3 – להקה (22 נקודות)
מדפיסים כמה מילים יש בשם הלהקה (בלי לולאה), ובונים ראשי תיבות באותיות גדולות.
```python
band = "red hot chili peppers"

words = band.count(" ") + 1
initials = band[0].upper()
for i in range(1, len(band)):
    if band[i - 1] == " ":
        initials += band[i].upper()
print("Words:", words)
print("Initials:", initials)
```
```text
Words: 4
Initials: RHCP
```
פתרונות נוספים שמקבלים:
```python
# also accepted for full marks
words = len(band.split(" "))
```
| סימן | קוד שגוי | סיבה |
|---|---|---|
| מספר המילים קטן באחד | `band.count(" ")` | מספר הרווחים קטן באחד ממספר המילים |
| ראשי התיבות בלי המילה הראשונה | הלולאה בלי האות הראשונה | לפני המקום 0 אין תו, ולכן מוסיפים אותו בנפרד |
| ראשי התיבות כוללים רווחים | `initials += band[i - 1]` | הוסיפו את הרווח ולא את התו שאחריו |

ניקוד: מספר מילים 6, ראשי תיבות 16 (האות הראשונה 3, תחילת הלולאה 3, הבדיקה אחרי רווח 5, הוספה באות גדולה 3, הדפסה 2).

## שאלה 4 – צופן הזזה (25 נקודות)
כל אות בטקסט זזה שתי אותיות קדימה באלף-בית, והרווח נשאר.
```python
text = "hello world"

coded = ""
for ch in text:
    if ch.isalpha():
        coded += chr(ord(ch) + 2)
    else:
        coded += ch
print("Coded:", coded)
```
```text
Coded: jgnnq yqtnf
```
פתרונות נוספים שמקבלים:
```python
# also accepted
if ch != " ":
    coded += chr(ord(ch) + 2)
```
אם התלמיד הוסיף את בדיקת החזרה להתחלה מהשיעור, התשובה זהה, כי בדוגמה אין אות שחוזרת להתחלה.
| סימן | קוד שגוי | סיבה |
|---|---|---|
| שגיאת סוג בתוך הלולאה | `coded += ord(ch) + 2` | לא החזירו את המספר לתו עם הפעולה המתאימה |
| הרווח הפך לתו אחר | הזזה בלי בדיקה | הזיזו גם את הרווח |

ניקוד: איפוס המחרוזת 3, לולאה על התווים 4, בדיקת אות 4, הזזה והחזרה לתו 7, התו שאינו אות נשאר 4, הדפסה אחרי הלולאה 3.

## שאלה 5 – קוד מספרים (25 נקודות)
בונים לכל אות את המקום שלה באלף-בית, מופרדים במקפים וללא מקף בסוף, ומדפיסים גם את הסכום.
```python
word = "snow"

numbers = ""
total = 0
for ch in word:
    place = ord(ch) - 96
    if numbers != "":
        numbers += "-"
    numbers += str(place)
    total += place
print("Number code:", numbers)
print("Total:", total)
```
```text
Number code: 19-14-15-23
Total: 71
```
פתרונות נוספים שמקבלים:
```python
# also accepted
place = ord(ch) - ord("a") + 1
print("Number code:", numbers[:-1])
```
| סימן | קוד שגוי | סיבה |
|---|---|---|
| שגיאת סוג | `numbers += ord(ch) - 96` | חיבור מספר למחרוזת בלי המרה |
| מקף אחרי המספר האחרון | מקף אחרי כל מספר | שאלה מכוונת: מה שונה במספר הראשון? |

ניקוד: איפוס המחרוזת והסכום 4, חישוב המקום 5, המרה למחרוזת 4, מקף רק בין מספרים 7, סכום 3, הדפסה 2.

## אתגר – צופן המראה (לא נבדק)
האות הראשונה באלף-בית הופכת לאחרונה, השנייה לאחת לפני האחרונה וכן הלאה. אות גדולה נשארת גדולה, רווחים וסימנים לא משתנים. מפעילים את הצופן פעמיים ובודקים שחוזרים להודעה המקורית.
```python
text = "Hello World"

# every pair has the same sum, so mirror = sum - ord(ch)
mirror = ""
for ch in text:
    if ch.isalpha():
        if ch == ch.lower():
            mirror += chr(ord("a") + ord("z") - ord(ch))
        else:
            mirror += chr(ord("A") + ord("Z") - ord(ch))
    else:
        mirror += ch
print("Mirror:", mirror)

# the same steps again, on the result
back = ""
for ch in mirror:
    if ch.isalpha():
        if ch == ch.lower():
            back += chr(ord("a") + ord("z") - ord(ch))
        else:
            back += chr(ord("A") + ord("Z") - ord(ch))
    else:
        back += ch
print("Back:", back)
if back == text:
    print("Same: yes")
else:
    print("Same: no")
```
```text
Mirror: Svool Dliow
Back: Hello World
Same: yes
```
הרעיון: בכל זוג אותיות סכום המספרים זהה, ולכן ההפוך של אות הוא הסכום פחות המספר שלה. לאותיות גדולות משתמשים בסכום של האותיות הגדולות.
| סימן | קוד שגוי | סיבה |
|---|---|---|
| אות גדולה הפכה לקטנה | סכום של קטנות על כל האותיות | לא הפרידו בין גדולות לקטנות |
| אחרי הפעלה שנייה לא חוזרים להודעה | `ord("z") - ord(ch)` | חסר החיבור עם האות הראשונה |
