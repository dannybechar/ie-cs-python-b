# יחידה 5 – מחרוזות: טבלת כל פקודות המחרוזת

כל הדוגמאות הורצו ב-Python 3.14. בדוגמאות המשתנים הם:

```python
word = "banana"
s = "Hello World"
```

**חשוב:** מחרוזת לא משתנה. כל פעולה ומתודה מחזירה מחרוזת חדשה - צריך לשמור אותה במשתנה או להדפיס אותה.

## א. פעולות ופונקציות

<div dir="rtl">

| פקודה | מה היא עושה | דוגמה | תוצאה |
|---|---|---|---|
| `len(x)` | מספר התווים (גם רווחים) | `len(word)` | 6 |
| `a + b` | חיבור מחרוזות | `"ab" + "cd"` | abcd |
| `a * n` | חזרה n פעמים | `"ab" * 3` | ababab |
| `x in text` | האם `x` נמצא בטקסט (True/False) | `"an" in word` | True |
| `text[i]` | התו במקום i (מתחילים מ-0) | `word[0]` | b |
| `text[-1]` | התו האחרון (ספירה מהסוף) | `word[-1]` | a |
| `text[a:b]` | חיתוך: מקום a עד b, **בלי** b | `word[1:4]` | ana |
| `text[:b]` | מהתחלה עד b (בלי b) | `word[:2]` | ba |
| `text[a:]` | ממקום a עד הסוף | `word[3:]` | ana |
| `for ch in text:` | עובר על התווים אחד אחד | `for ch in "ab": print(ch)` | a ואז b |
| `ord(ch)` | מספר הקוד של תו | `ord("a")` | 97 |
| `chr(n)` | התו של מספר קוד | `chr(98)` | b |

</div>

## ב. מתודות (כותבים נקודה אחרי המחרוזת)

<div dir="rtl">

| מתודה | מה היא עושה | דוגמה | תוצאה |
|---|---|---|---|
| `.upper()` | כל האותיות גדולות | `s.upper()` | HELLO WORLD |
| `.lower()` | כל האותיות קטנות | `s.lower()` | hello world |
| `.count(x)` | כמה פעמים `x` מופיע | `word.count("a")` | 3 |
| `.find(x)` | המקום הראשון של x | `word.find("n")` | 2 |
| `.find(x)` | אם x לא נמצא מקבלים מינוס 1 | `word.find("x")` | -1 |
| `.replace(a, b)` | מחליף כל `a` ב-`b` | `word.replace("a", "o")` | bonono |
| `.startswith(x)` | האם מתחיל ב-`x` | `s.startswith("He")` | True |
| `.endswith(x)` | האם מסתיים ב-`x` | `s.endswith("d")` | True |
| `.isalpha()` | האם כל התווים אותיות | `"a".isalpha()` | True |
| `.isdigit()` | האם כל התווים ספרות | `"5".isdigit()` | True |
| `.isdigit()` | בודק את כל התווים, אז מחרוזת מעורבת נותנת False | `"a5".isdigit()` | False |
| `.split()` | מפצל למילים (מוצג בלבד; רשימות ביחידה 7) | `"a b c".split()` | ['a', 'b', 'c'] |
| `"-".join(x)` | מחבר את התווים עם מפריד (מוצג בלבד) | `"-".join("abc")` | a-b-c |

</div>

## ג. טעויות נפוצות

<div dir="rtl">

| הקוד השגוי | מה לא בסדר | תיקון |
|---|---|---|
| `s.upper()` | התוצאה לא נשמרה, והמחרוזת המקורית לא השתנתה | `s = s.upper()` |
| `word[6]` | אין מקום 6 במחרוזת באורך 6 (המקומות הם 0 עד 5) | `word[5]` |
| `"a5".isdigit()` | הבדיקה היא על כל התווים ולא על "יש ספרה" | `if ch.isdigit():` |
| `word[1:4]` | המקום האחרון לא נכלל, ולכן מקבלים ana ולא anan | `word[1:5]` |

</div>
