קוראים ← חוזים ← מריצים ← בודקים ← מתקנים

IMPORTANT

הלולאה while חוזרת כל עוד התנאי True. למשתנה הלולאה נותנים ערך התחלתי לפני הלולאה, ומשהו בתוך הלולאה חייב לשנות אותו — בכיוון הנכון.

דף עזר

n = 0                  # 1. הכנה: ערך התחלתי, לפני הלולאה
while n < 10:          # 2. תנאי: נבדק לפני כל סבב
    print("hi")        # 3. גוף הלולאה
    n = n + 1          # 4. עדכון: בתוך הלולאה
print("End loop")
  • עשרה סבבים — אחד-עשר בדיקות של התנאי. הבדיקה האחרונה נותנת False.
  • משתנה שהמשתמש מקליד: קולטים לפני הלולאה וגם בתוך הלולאה.
  • n += 1 זה קיצור של n = n + 1, ו-n -= 1 של n = n - 1.
  • for i in range(0, 5, 1) זה i = 0, while i < 5, ועדכון i += 1.

רשימת בדיקה ללולאה בטוחה:

  1. יש ערך התחלתי לפני הלולאה?
  2. התנאי יכול להפוך ל-False?
  3. יש בתוך הלולאה פקודה שמשנה את המשתנה של התנאי?
  4. העדכון מקרב אותנו לעצירה (הכיוון נכון)?

TIP

לולאה שלא נעצרת? שומרים את הקובץ ולוחצים על כפתור Stop האדום ב-Thonny.

0. חוזים לפני שמריצים

n = 0
while n < 10:
    print("hi")
    n = n + 1
print("End loop")

כמה פעמים יודפס hi? כמה פעמים נבדק התנאי n < 10? מלאו טבלת מעקב: n, התנאי, הפלט. אחר כך הריצו ובדקו.

1. חימום: השאלה שלא חוזרת

פתחו את While_Starter.py.

def ask_age():
    age = int(input("Age: "))
    while age < 0:
        print("Invalid age")
    print("Accepted:", age)

הריצו והקלידו מינוס 2. למה התוכנית לא נעצרת? עצרו אותה (כפתור Stop) והוסיפו שורה אחת. בדקו עם מינוס 2, מינוס 1 ו-0. איזו נקודה ברשימת הבדיקה הייתה חסרה?

2. משימה 1: מספר תלת-ספרתי

כתבו פונקציה בשם three_digit(): קולטת מספר שלם, ושואלת שוב ושוב כל עוד המספר אינו תלת-ספרתי (מ-100 עד 999). בסוף מדפיסה End loop.

בדקו עם 5, 1000, מינוס 3, 123. כתבו שני ערכים שעבורם יודפס End loop מיד, ושני ערכים שעבורם יידרש קלט חדש.

3. משימה 2: עד שלושה מספרים זוגיים

כתבו פונקציה בשם three_evens(): קולטת מספרים שלמים עד שהוקלדו 3 מספרים זוגיים, ואז מדפיסה End loop.

קודם מלאו על דף: מה הערך ההתחלתי של count? מה התנאי? מתי count גדל? מלאו טבלת מעקב לקלט 3, 4, 6, 7, 8 — כמה סבבים היו? מה הערך האחרון של count?

4. משימה 3: ניקוד וטיימר

כתבו פונקציה בשם score_and_timer(): קודם ספירה קדימה של הניקוד מ-0 עד 10 (Score: 0 … Score: 10), אחר כך ספירה לאחור של טיימר מ-10 עד 1 (Timer: 10 … Timer: 1), ובסוף Time is up!.

מה שונה בין שתי הלולאות: ערך ההתחלה, התנאי, העדכון?

8. משימה 7 (יחד): מספר מעורר

מספר מעורר הוא מספר שלם שבו סכום כל הספרות גדול פי שלושה או יותר ממספר הספרות. (שאלה מבחינת מפמ"ר פייתון א.) קלטו מספר והדפיסו אם הוא מעורר: Exciting number או Not an exciting number.

  • num % 10 — הספרה האחרונה. num // 10 — המספר בלי הספרה האחרונה.
  • קודם מעקב: מלאו טבלה למספר 789: num, digit, total, digits בכל סבב. אחר כך בדקו את 100.
  • אחר כך הרצה: כתבו את exciting_number() בעזרת התוכנית שבקובץ. בדקו 789, 100, 99, 123.

9. משימה 8: סכום של חזקות שלישיות — בדיקת סיום היחידה

עבודה עצמית. כתבו פונקציה בשם cubes_sum() שמחברת 1 + 8 + 27 + … (החזקות השלישיות: 1·1·1, 2·2·2, 3·3·3 …) כל עוד הסכום קטן מ-100. אחרי כל איבר מדפיסים Sum so far: ..., ובסוף Stopped at ... after ... terms.

תכננו על דף לפני שמקלידים: אילו משתנים צריך ומה ערכם ההתחלתי? מה התנאי? מה משתנה בכל סבב? הפלט הצפוי: סכומים 1, 9, 36, 100 ואחר כך Stopped at 100 after 4 terms.

10. אם נשאר זמן

  • count_red() — קולטים צבעי חרוזים אחד אחד. אחרי כל צבע שואלים Do you want to continue? yes/no, וממשיכים כל עוד התשובה yes. בסוף מדפיסים The number of red beads is: .... בדקו עם red, yes, blue, yes, red, no — צריך לצאת 2.
  • twos() — מדפיסה את הסדרה 2, 22, 222, 2222 … כל עוד האיבר קטן מ-10000.
  • alternating_squares() — הסדרה -1 + 4 - 9 + 16 - 25 + 36 …: הסימן מתחלף בכל איבר. הדפיסו את הסכום אחרי כל איבר, וכל עוד ריבוע האיבר הבא קטן מ-50. רמז: משתנה sign שמכפילים ב-(-1) בכל סבב.
  • factorial_sum() — הסדרה 1 + 2 + 6 + 24 + 120 …: כל איבר הוא האיבר הקודם כפול מונה שגדל. הדפיסו את הסכום אחרי כל איבר, כל עוד הסכום קטן מ-1000.
