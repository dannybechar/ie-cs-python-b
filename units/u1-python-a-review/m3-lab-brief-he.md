# יחידה 1.3 – חזרה על פייתון א'

כיתה ח׳ · AI + Python B · **עד שמסיימים: לולאת while והמנעול עם שלושה ניסיונות**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> הלולאה `while` חוזרת כל עוד התנאי `True`. משהו בתוך הלולאה חייב לקרב אותה לסיום — בכל מקרה.

## דף עזר

```python
age = int(input("Age: "))
while age < 0 or age > 120:
    print("Invalid age")
    age = int(input("Age: "))
print("Accepted:", age)
```

<div dir="rtl">

- ערך התחלה — לפני הלולאה.
- תנאי — נבדק לפני כל סבב.
- עדכון — בתוך הלולאה. בבדיקת קלט: קולטים שוב בסוף הסבב.
- מספר הסבבים ידוע מראש ← `for`. הסיום תלוי במה שקורה ← `while`.

</div>

> [!TIP]
> לולאה שלא נעצרת? לוחצים על כפתור Stop האדום ב-Thonny.

## 3. משימה 2: המנעול

רמז: הלולאה ממשיכה כל עוד נשארו ניסיונות **וגם** הקוד עוד לא נמצא.

## 4. משימה 3: יעד הנקודות — בדיקת סיום היחידה

עבודה עצמית. כתבו פונקציה בשם `points_goal()`:

<div dir="rtl">
