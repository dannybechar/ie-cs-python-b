כיתה ח׳ · AI + Python B · **עד שמסיימים: לולאת while ולולאות שלא נגמרות**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> הלולאה `while` חוזרת כל עוד התנאי `True`. למשתנה הלולאה נותנים ערך התחלתי **לפני** הלולאה, ומשהו **בתוך** הלולאה חייב לשנות אותו — **בכיוון הנכון**.

## דף עזר

```python
n = 0                  # 1. הכנה: ערך התחלתי, לפני הלולאה
while n < 10:          # 2. תנאי: נבדק לפני כל סבב
    print("hi")        # 3. גוף הלולאה
    n = n + 1          # 4. עדכון: בתוך הלולאה
print("End loop")
```

<div dir="rtl">

- עשרה סבבים — **אחד-עשר** בדיקות של התנאי. הבדיקה האחרונה נותנת `False`.
- משתנה שהמשתמש מקליד: קולטים **לפני** הלולאה וגם **בתוך** הלולאה.
- `n += 1` זה קיצור של `n = n + 1`, ו-`n -= 1` של `n = n - 1`.
- `for i in range(0, 5, 1)` זה `i = 0`, `while i < 5`, ועדכון `i += 1`.

**רשימת בדיקה ללולאה בטוחה:**

1. יש ערך התחלתי לפני הלולאה?
2. התנאי יכול להפוך ל-`False`?
3. יש בתוך הלולאה פקודה שמשנה את המשתנה של התנאי?
4. העדכון מקרב אותנו לעצירה (הכיוון נכון)?

</div>

> [!TIP]
> לולאה שלא נעצרת? שומרים את הקובץ ולוחצים על כפתור Stop האדום ב-Thonny.

## 8. משימה 7 (יחד): מספר מעורר

<div dir="rtl">

**מספר מעורר** הוא מספר שלם שבו סכום כל הספרות גדול פי שלושה **או יותר** ממספר הספרות. (שאלה מבחינת מפמ"ר פייתון א.) קלטו מספר והדפיסו אם הוא מעורר: `Exciting number` או `Not an exciting number`.

- `num % 10` — הספרה האחרונה. `num // 10` — המספר בלי הספרה האחרונה.
- **קודם מעקב:** מלאו טבלה למספר 789: `num`, `digit`, `total`, `digits` בכל סבב. אחר כך בדקו את 100.
- **אחר כך הרצה:** כתבו את `exciting_number()` בעזרת התוכנית שבקובץ. בדקו 789, 100, 99, 123.

</div>
