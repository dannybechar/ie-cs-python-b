```python
def classifier():
    years = [1889, 1519, 1906, 1893]
    paintings = ["Starry Night", "Mona Lisa", "Water Lilies", "The Scream"]
    classic = []
    modern = []
    for i in range(len(paintings)):
        if years[i] < 1860:
            classic.append(paintings[i])
        else:
            modern.append(paintings[i])
    print("classic:", classic)
    print("modern:", modern)
```

```python
        return "apple"
    elif softness > 2 and color in ["yellow", "green"]:
        return "banana"
    else:
        return "unknown fruit"
```

## 2. משימה 1: מסווג פלייליסטים (ספוטיפיי)

<div dir="rtl">

בספוטיפיי רוצים ליצור פלייליסטים אוטומטיים. שירים שיצאו **לפני** שנת הפיצול נכנסים לרשימה `nostalgia` (פלייליסט נוסטלגיה), ואחרים לרשימה `hits` (פלייליסט להיטים עכשווים). כתבו לולאה עם שתי רשימות מקבילות (שירים ושנים) ושתי רשימות ריקות.

א. הריצו עם שנת פיצול 2015. אחר כך **בחרו שנת פיצול משלכם** (לדוגמה 2010 או 2020) ושנו אותה בתנאי.

ב. מה יודפס אחרי השינוי? השלימו את טבלת המעקב לפני שמריצים (השורה הראשונה כתובה לדוגמה).

ג. הריצו ובדקו שהסיווג נכון.

## 5. משימה 4: פעולת סיווג ומקרי קצה

<div dir="rtl">

כתבו `classify_fruit(softness, color)`. הכללים:

- תפוח: רכות קטנה מ-2 והצבע אדום, ירוק או צהוב.
- בננה: רכות גדולה מ-2 והצבע צהוב או ירוק.
- כל השאר: `"unknown fruit"`.

קראו לפעולה שלוש פעמים והדפיסו את התוצאה עבור הקלטים שבטבלה. אחר כך נסו לשבור אותה.

</div>

## 6. משימה 5: שאלה למחשבה

<div dir="rtl">

מתכנת הציע את החוק: אם קצב השיר גבוה מ-120 הוא "שמח", אחרת הוא "עצוב". מצאו שיר או סגנון שבו החוק נכשל, והסבירו למה קשה להגדיר "מצב רוח" בעזרת `if/else`.

**אם נשאר זמן (פיצ׳רים מתקדמים):** כתבו תוכנית נוספת שמסווגת משהו לבחירתכם. רעיונות: **כלי תחבורה** (מספר גלגלים, איפה נוסע, מהירות, מנוע, כידון או הגה עגול), **בעלי חיים** (יונק, ציפור או דג לפי מספר רגליים, כיסוי גוף, צבע, דרך תנועה), **צורה הנדסית** (מספר צלעות, סכום זוויות), או רעיון משלכם. השתמשו ברשימות מקבילות, רשימה ריקה לכל קטגוריה, ובדקו ערכי גבול.
