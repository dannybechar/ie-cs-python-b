## דף עזר

```python
def has_leak(train_ids, test_ids):
    for test_id in test_ids:
        if test_id in train_ids:
            return True
    return False
```

<div dir="rtl">

- **אימון:** המחשב מקבל דוגמאות ו"דף תשובות" ומזיז את הקו אחרי כל טעות.
- **מבחן:** דוגמאות חדשות, הקו כבר לא זז, והמחשב רק נותן לעצמו ציון.
- **Confidence** שייך לתחזית אחת. מודל יכול לטעות ברמת ביטחון גבוהה.

</div>

## 1. חימום: דליפה שלא נתפסה

פתחו את `TrainTest_Starter.py`.

```python
def has_leak(train_ids, test_ids):
    return train_ids == test_ids


train_ids = ["img1", "img2", "img3"]
test_ids = ["img2", "img9"]
print(has_leak(train_ids, test_ids))
```

<div dir="rtl">

חזו `True` (`"img2"` נמצא בשני הסטים), הריצו — מקבלים `False`. השוואת שתי רשימות שלמות אינה בדיקה אם איבר בודד נמצא בשתיהן. תקנו: עברו על `test_ids` ובדקו `in train_ids`.

</div>

## 4. משימה 1: describe_trial

<div dir="rtl">

כתבו `describe_trial(true_label, predicted, confidence)` שמחזירה שורה אחת:

</div>

```text
<true_label> -> <predicted> (confidence <confidence>) - correct
<true_label> -> <predicted> (confidence <confidence>) - WRONG
```

<div dir="rtl">

בדקו על `("fist", "fist", 0.91)` ועל `("ok", "fist", 0.55)`, ואחר כך הפעילו אותה על שתי שורות אמיתיות מהטבלה שלכם (91% נכתב 0.91).

</div>
