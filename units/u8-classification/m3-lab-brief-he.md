def calculate_accuracy(successes, attempts):
    if attempts == 0:
        return 0
    return successes / attempts * 100

## 1. חימום: מאוזן, לכיוון הלא נכון

פתחו את `DataPlan_Starter.py`.

```python
def check_balance(fist_count, ok_count):
    total = fist_count + ok_count
    fist_share = fist_count / total * 100
    if fist_share > 50:
        print("fist is under-represented")
    else:
        print("Balanced enough")


check_balance(20, 80)
```

<div dir="rtl">

חזו אזהרה (תמונות fist הן רק 20% מהנתונים), הריצו — מקבלים `Balanced enough`. התנאי בודק חלק **גבוה**, לא נמוך. תקנו: סמנו כל קטגוריה שמתרחקת מדי מחלוקה שווה (מתחת ל-40% או מעל 60%).

## 2. משימה 1: calculate_accuracy

<div dir="rtl">

כתבו `calculate_accuracy(successes, attempts)` שמחזירה את הדיוק באחוזים: ההצלחות חלקי הניסיונות כפול 100. אם לא היו ניסיונות, החזירו 0. בדקו על הדוגמה מהמצגת: 2 הצלחות מתוך 4 ניסיונות (מצופה `50.0`), ועל 6 מתוך 7. תשתמשו בה בסוף העבודה על המודל האמיתי שלכם.

</div>
