def calculate_accuracy(successes, attempts):
    if attempts == 0:
        return 0
    return successes / attempts * 100

1. חימום: מאוזן, לכיוון הלא נכון

פתחו את DataPlan_Starter.py.

def check_balance(fist_count, ok_count):
    total = fist_count + ok_count
    fist_share = fist_count / total * 100
    if fist_share > 50:
        print("fist is under-represented")
    else:
        print("Balanced enough")


check_balance(20, 80)

חזו אזהרה (תמונות fist הן רק 20% מהנתונים), הריצו — מקבלים Balanced enough. התנאי בודק חלק גבוה, לא נמוך. תקנו: סמנו כל קטגוריה שמתרחקת מדי מחלוקה שווה (מתחת ל-40% או מעל 60%).

2. משימה 1: calculate_accuracy

כתבו calculate_accuracy(successes, attempts) שמחזירה את הדיוק באחוזים: ההצלחות חלקי הניסיונות כפול 100. אם לא היו ניסיונות, החזירו 0. בדקו על הדוגמה מהמצגת: 2 הצלחות מתוך 4 ניסיונות (מצופה 50.0), ועל 6 מתוך 7. תשתמשו בה בסוף העבודה על המודל האמיתי שלכם.

3. משימה 2: check_variety

כתבו check_variety(labels, counts, minimum) שמזהירה, בשם, על כל גורם שמספר התמונות שלו נמוך מ-minimum, סופרת את האזהרות, ואם אין אזהרות מדפיסה Every factor meets the minimum. בדקו על:

labels = ["bright background", "dark background", "side light", "new user"]
counts = [40, 5, 15, 3]
minimum = 10

אם נשאר זמן: כתבו count_covered(required, tested) שסופרת כמה מניסויי ההטיה הנדרשים כבר בוצעו. בדקו על required = ["background", "lighting", "user", "angle"] ו-tested = ["lighting", "angle"].

4. הפרויקט: אגרוף או OK

  1. פתחו ב-Teachable Machine Image Project עם שתי קטגוריות: fist ו-ok, והעלו את תמונות האימון שקיבלתם (תמונות לאימון).
  2. הוסיפו תמונות משלכם (ידיים בלבד). לפני האימון ענו: האם קטגוריה אחת קשורה לרקע אחד או ליד אחת? האם מספר התמונות דומה? האם יש תמונות מטושטשות או מתויגות לא נכון? אפשר לנחש את הקטגוריה לפי הרקע בלבד?
  3. הריצו ניסוי הטיה אחד: שנו גורם אחד בלבד (רקע, תאורה, יד או זווית), ותעדו בטבלה.
  4. אמנו. המורה יחלק 7 תמונות מבחן שהמודל לא ראה. סווגו כל אחת, ספרו הצלחות וחשבו דיוק בעזרת הפעולה ממשימה 1.
  5. שמרו את המודל: Export Model ← האפשרויות המסומנות באדום ← בדקו שירד קובץ converted_savedmodel.zip, ושלחו אותו לעצמכם.
