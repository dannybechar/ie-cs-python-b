# יחידה 6.1 – מודל שפה מתקדם

כיתה ח׳ · AI + Python B · **טוקנים, טוקניזציה ומזהים**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> טוקן הוא יחידת עיבוד של מודל מסוים — מילה, חלק ממילה, מספר, רווח או סימן פיסוק. מספר הטוקנים אינו מספר המילים, והוא תלוי בטוקנייזר, בשפה ואפילו באותיות גדולות.

## דף עזר

```text
טקסט → טוקנייזר → טוקנים → מזהים מספריים → המודל
```

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")
tokenizer = model.tokenizer

tokens = tokenizer.tokenize("hello world")
token_ids = tokenizer.convert_tokens_to_ids(tokens)
```

<div dir="rtl">

הסימן `▁` בתחילת טוקן אומר "כאן מתחילה מילה". אותו טוקן מקבל תמיד את אותו מזהה.

</div>

## 5. מעבדת ניסויים

<div dir="rtl">

המטרה היא לחקור — זה בסדר גמור אם לא תפתרו הכול. תעדו כל ניסוי: מה חזיתם ← מה קיבלתם ← מה למדתם.

1. **שם:** כמה טוקנים נוצרו משמכם באנגלית ובעברית?
2. **שפות:** האם אותו משפט בעברית ובאנגלית מקבל אותו מספר טוקנים?
3. **מילה בת 5 אותיות:** מצאו בעשרה ניסיונות מילה שמתפרקת להכי הרבה טוקנים.
4. **אותיות גדולות:** האם `apple` ו-`APPLE` זהים? השוו את המזהים.
