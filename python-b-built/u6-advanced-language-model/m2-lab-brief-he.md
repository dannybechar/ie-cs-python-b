## 1. חימום: מודדים את הדבר הלא נכון

פתחו את `Meanings_Starter.py`.

```python
def shared_letters(word_a, word_b):
    count = 0
    for character in word_a:
        if character == word_b:
            count += 1
    return count


print(shared_letters("מזוודה", "מוזיקה"))
```

חזו מספר חיובי (יש תווים משותפים), הריצו — מקבלים `0`. השוואת תו יחיד למחרוזת שלמה אף פעם לא תואמת. תקנו: `character in word_b`.

## 2. משימה: ציון איות לעומת "משמעות" מדומה

הקובץ מספק את `meaning_score_demo(guess, target)` — **לא** מודל AI אמיתי, אלא מדמה מבוסס חוקים עם כמה תשובות קבועות (כולן עבור המילה `מוזיקה`) וברירת מחדל לכל השאר. עבור כל מילה, הדפיסו את ציון האיות שלה מול `מוזיקה` (`shared_letters` המתוקנת) ואת ציון "המשמעות" (`meaning_score_demo`), וכתבו משפט אחד שמסביר מה ההשוואה מראה:

<div dir="rtl">

| מילה | תווים משותפים עם "מוזיקה" | ציון "משמעות" (מדומה) |
|---|---:|---:|
| פסנתר | 0 | 0.82 |
| שיר | 1 | 0.76 |
| כדורגל | 1 | 0.19 |
| מזוודה | 5 | 0.35 |

</div>

`פסנתר` לא חולקת אף תו עם `מוזיקה`, ובכל זאת מקבלת ציון "משמעות" גבוה — איות ומשמעות בלתי תלויים זה בזה. `מזוודה` חולקת חמישה תווים (נראית קרובה באיות!) אבל אין לה קשר למוזיקה.
