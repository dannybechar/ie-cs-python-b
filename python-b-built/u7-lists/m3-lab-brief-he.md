> [!IMPORTANT]
> אף פעם לא מוחקים מרשימה תוך כדי מעבר ישיר עליה — בונים רשימה חדשה במקום. פונקציית סכימה מאתחלת לפני הלולאה, מעדכנת בכל סבב, ומחזירה אחריה.

## דף עזר

```python
values = [1, 2, 3, 4, 5, 6]
odd_values = []
for value in values:
    if value % 2 != 0:
        odd_values.append(value)   # בונים רשימה חדשה — לא מוחקים מזו שעוברים עליה
```

```python
def calculate_total(values):
    total = 0                       # 1. אתחול לפני הלולאה
    for value in values:
        total += value                # 2-3. מעבר, עדכון
    return total                       # 4. שימוש בתוצאה אחרי הלולאה
```

## 1. חימום: נעלם בגלל הזזה

פתחו את `Accumulate_Starter.py`.

```python
values = [2, 4, 6, 8, 10]
for value in values:
    if value % 2 == 0:
        values.remove(value)

```

חזו `[]` (כל הערכים זוגיים), הריצו — מקבלים `[4, 8]`. מחיקה מזיזה כל איבר מאוחר יותר מקום אחד שמאלה, אבל מיקום הלולאה ממשיך להתקדם בכל זאת — חלק מהאיברים לעולם לא נבדקים. תקנו: בנו רשימה חדשה של מה שרוצים **לשמור**.
