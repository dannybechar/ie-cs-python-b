## דף עזר

```python
def linear_search(values, target):
    for index in range(len(values)):
        if values[index] == target:
            return index
    return -1


position = linear_search(scores, 81)
if position != -1:              # השוואה מפורשת — אינדקס 0 הוא הצלחה תקינה
    print("Found at", position)
```

## 1. חימום: נמצא באינדקס 0, דווח כלא נמצא

פתחו את `Analyzer_Starter.py`.

```python
scores = [81, 24, 67, 91]
if linear_search(scores, 81):
    print("Found")
else:
    print("Not found")
```

חזו `Found` (81 נמצא ממש באינדקס 0), הריצו — מקבלים `Not found`. `if 0:` הוא `False` בפייתון, למרות שאינדקס 0 הוא הצלחה אמיתית. תקנו: שמרו את התוצאה במשתנה והשוו במפורש ל-`-1`.

## 2. משימה 1: linear_search_sorted(values, target)

עוצרת ברגע שהאיבר הנוכחי אינו קטן יותר מהמטרה. בדקו על `[10, 20, 35, 50, 80]` עם מטרה 35 (קיימת) ועם מטרה 40 (לא קיימת).

## 3. משימה 2 (פרויקט): "מנתח ניסויי AI" — בדיקת סיום היחידה

בנו תוכנית ש: קולטת ציוני דמיון עם `input()` עד `-1` (הזקיף — לא נשמר), שומרת רק ציונים בין 0 ל-100; מדפיסה כמות, ממוצע, מינימום ומקסימום; יוצרת **עותק** ממוין בלי לשנות את המקורית; קולטת סף ומדפיסה כמה ציונים עברו אותו; קולטת ציון יעד ומדפיסה את מיקומו ברשימה הממוינת. השתמשו בכל הפונקציות מיחידות 7.1–7.4 כקופסאות שחורות — אל תממשו מחדש את הלוגיקה שלהן.
