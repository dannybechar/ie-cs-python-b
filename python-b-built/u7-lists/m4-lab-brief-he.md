> [!IMPORTANT]
> מונה גדל רק כשהתנאי מתקיים. מינימום ומקסימום מאותחלים מהאיבר הראשון של הרשימה — אף פעם לא מ-0.

## דף עזר

```python
def find_maximum(values):
    if len(values) == 0:
        return None
    largest = values[0]            # מתחילים מערך אמיתי ברשימה, לא מ-0
    for value in values:
        if value > largest:
            largest = value
    return largest
```

<div dir="rtl">

אם כל הערכים שליליים, `largest = 0` לעולם לא יוכה — הפונקציה תחזיר בטעות `0`, ערך שאפילו לא ברשימה.

</div>

## 1. חימום: המקסימום שלא מתעדכן

פתחו את `Stats_Starter.py`.

```python
def find_maximum(values):
    largest = 0
    for value in values:
        if value > largest:
            largest = value
    return largest


print(find_maximum([-5, -2, -9]))
```

חזו `-2` (הגדול משלושת הערכים), הריצו — מקבלים `0`. תקנו: `largest = values[0]`.

## 2. משימה 1: count_above ו-count_in_range

`count_above(values, threshold)` ו-`count_in_range(values, low, high)` (כולל שני הגבולות). בדקו שתיהן על `[81, 24, 67, 91]`.

## 3. משימה 2: find_minimum(values)

אותו תיקון כמו בחימום: `None` לרשימה ריקה, אחרת מאותחל מ-`values[0]`. בדקו על `[81, 24, 67, 91]` ועל `[]`.

## 4. משימה 3: build_report(values)

`"No data"` לרשימה ריקה; אחרת מחרוזת עם הכמות, הממוצע (מעוגל לספרה עשרונית אחת), המינימום והמקסימום — כל אחד בשורה משלו. בדקו על `[81, 24, 67, 91]`.

## 5. בדיקת מקרי קצה

<div dir="rtl">

| רשימה | תוצאה שיש לבדוק |
|---|---|
| `[]` | אין חלוקה באפס; מינימום ומקסימום מחזירים `None` |
| `[50]` | ממוצע, מינימום ומקסימום הם 50 |
| `[7, 7, 7]` | מינימום ומקסימום שווים |
| `[-5, -2, -9]` | המקסימום הוא `-2`, לא 0 |

</div>

## 6. דיון: מה ציון דמיון כן ולא אומר
