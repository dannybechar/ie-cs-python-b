# יחידה 3.1 – פעולות

כיתה ח׳ · AI + Python B · **פעולה כאבן בניין: בלי פרמטרים, בלי ערך חוזר**

**קוראים ← חוזים ← מריצים ← בודקים ← מתקנים**

> [!IMPORTANT]
> `def` מגדירה פעולה. רק זימון (קריאה בשם הפעולה עם סוגריים) מפעיל אותה — וה-`def` חייבת להופיע לפני הזימון.

## דף עזר

```python
def show_header():
    print("MISSION CONTROL")
    print("---------------")


show_header()
```

<div dir="rtl">

- `def` פותחת הגדרה. השם מתאר את התפקיד. הסוגריים ריקים כי אין פרמטרים.
- ההזחה קובעת אילו שורות שייכות לגוף הפעולה.
- פייתון קורא את כל ה-`def`-ים קודם, ואז מריץ את התכנית הראשית מלמעלה למטה.
- זימון לפני ה-`def` ← `NameError`.

</div>

## 1. חימום: זומנה לפני שהוכרה

פתחו את `Panel_Starter.py`.

```python
show_status()


def show_status():
    print("READY")
```

הריצו וקראו את השגיאה. העבירו שורה אחת כדי לתקן.

## 2. משימה 1: show_welcome()

הגדירו פעולה בשם `show_welcome()` — שתי שורות, בלי פרמטרים ובלי ערך חוזר. זמנו אותה פעמיים, עם הדפסה אחרת ביניהן. כתבו את הפלט הצפוי לפני שמריצים.

## 3. משימה 2 (מיני-פרויקט): לוח בקרה

הגדירו ארבע פעולות: `show_title`, `show_status`, `show_help`, `show_end` — כל אחת מדפיסה שורה אחת, בלי פרמטרים ובלי ערך חוזר. זמנו אותן בסדר הגיוני מהתכנית הראשית; זמנו את `show_status` פעמיים (פעם בהתחלה ופעם קרוב לסוף).

בנו **מלמטה למעלה**: כתבו ובדקו פעולה אחת בכל פעם, ורק אז חברו את כולן.

## 4. ביקורת עמיתים לפי שמות בלבד

מחליפים עם בן/בת זוג. הם קוראים רק את **שמות** הפעולות שלכם (לא את הגוף) ומנחשים מה התכנית עושה. אם הניחוש נכון — השמות ברורים. אם לא — שנו שם או פצלו פעולה שעושה יותר ממשימה אחת.
